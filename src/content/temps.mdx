## Temps (CEFR A1+)

### Le présent

> Sujet + présent

| Sujet      | 1er  | 2e      |
| ---------- | ---- | ------- |
| Je         | -e   | -is     |
| Tu         | -es  | -is     |
| Il/Elle/On | -e   | -it     |
| Nous       | -ons | -issons |
| Vous       | -ez  | -issez  |
| Ils/Elles  | -ent | -issent |

---

### Le passé composé

> Sujet + avoir / être (présent) + participe passé

| Sujet      | avoir/être   | 1er | 2e  |
| ---------- | ------------ | --- | --- |
| Je         | ai/suis      | -é  | -i  |
| Tu         | as/es        | -é  | -i  |
| Il/Elle/On | a/est        | -é  | -i  |
| Nous       | avons/sommes | -é  | -i  |
| Vous       | avez/êtes    | -é  | -i  |
| Ils/Elles  | ont/sont     | -é  | -i  |

### L'imparfait

> Sujet + imparfait

| Sujet      | 1er    | 2e        |
| ---------- | ------ | --------- |
| Je         | -ais   | -issais   |
| Tu         | -ais   | -issais   |
| Il/Elle/On | -ait   | -issait   |
| Nous       | -ions  | -issions  |
| Vous       | -iez   | -issiez   |
| Ils/Elles  | -aient | -issaient |

### Le plus-que-parfait

> Sujet + avoir / être (imparfait) + participe passé

| Sujet      | avoir / être    | 1er | 2e  |
| ---------- | --------------- | --- | --- |
| Je         | avais/étais     | -é  | -i  |
| Tu         | avais/étais     | -é  | -i  |
| Il/Elle/On | avait/était     | -é  | -i  |
| Nous       | avions/étions   | -é  | -i  |
| Vous       | aviez/étiez     | -é  | -i  |
| Ils/Elles  | avaient/étaient | -é  | -i  |

### Le conditionnel présent

> Sujet + conditionnel présent

> Si + Sujet + imparfait, Sujet + conditionnel présent

| Sujet      | 1er/2e |
| ---------- | ------ |
| Je         | -ais   |
| Tu         | -ais   |
| Il/Elle/On | -ait   |
| Nous       | -ions  |
| Vous       | -iez   |
| Ils/Elles  | -aient |

### Le conditionnel passé

> Sujet + avoir / être (conditionnel présent) + participe passé

> Si + Sujet + avoir / être (imparfait) + participe passé, Sujet + avoir / être (conditionnel présent) + participe passé

| Sujet      | avoir / être      | 1er | 2e  |
| ---------- | ----------------- | --- | --- |
| Je         | aurais/serais     | -é  | -i  |
| Tu         | aurais/serais     | -é  | -i  |
| Il/Elle/On | aurait/serait     | -é  | -i  |
| Nous       | aurions/serions   | -é  | -i  |
| Vous       | auriez/seriez     | -é  | -i  |
| Ils/Elles  | auraient/seraient | -é  | -i  |
