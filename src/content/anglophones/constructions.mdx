# La construction des verbes

## Liens utiles

- [Les verbes du français sur LA LANGUE FRANÇAISE](/cours/vocabulaire/verbes)
- [Les temps du français sur LA LANGUE FRANÇAISE](/cours/grammaire/temps)
- [Recherche de verbes sur Larousse](https://www.larousse.fr/dictionnaires/francais-monolingue)
- [Banque de dépannage linguistique sur la Vitrine linguistique](https://vitrinelinguistique.oqlf.gouv.qc.ca/)

> Pour chaque verbe : la préposition devant un nom ou un infinitif, et le mode après **que**. Les exemples sont faits pour être réutilisés tels quels, à l'écrit comme à l'oral.

## Repères

- **qqn** = quelqu'un, **qqch** = quelque chose
- **∅** = pas de préposition
- **inf.** = infinitif, **ind.** = indicatif, **subj.** = subjonctif

### Trois questions à se poser

| Question              | Réponse                                             | Exemple                                                         |
| --------------------- | --------------------------------------------------- | --------------------------------------------------------------- |
| Qui fait l'action ?   | même sujet → infinitif                              | Je veux partir.                                                 |
|                       | deux sujets différents → que + verbe conjugué       | Je veux que tu partes.                                          |
| Quelle préposition ?  | ∅, à ou de : elle s'apprend avec le verbe           | J'ose demander. / J'apprends à nager. / J'essaie de comprendre. |
| Un fait ou une idée ? | un fait, une certitude, une déclaration → indicatif | Je sais qu'il vient.                                            |
|                       | une volonté, un sentiment, un doute → subjonctif    | Je veux qu'il vienne.                                           |

> La préposition décide aussi du pronom : **à** → y, lui, leur ; **de** → en, dont.

> Devant **que**, **à** et **de** deviennent souvent **à ce que** et **de ce que** : Je tiens à ce que tu sois là.

### demander ou exiger

| Construction                        | Exemple                                           |
| ----------------------------------- | ------------------------------------------------- |
| demander qqch (à qqn)               | Il demande un café.                               |
| demander à qqn de + inf.            | Je lui ai demandé de venir.                       |
| demander que + subj.                | Il demande que tu viennes.                        |
| exiger qqch                         | Il exige un rapport.                              |
| exiger de + inf. (même sujet)       | J'exige de parler au directeur.                   |
| exiger que + subj.                  | Il exige que tu viennes.                          |
| exiger de qqn que + subj. (soutenu) | Il exige de ses employés qu'ils soient ponctuels. |

> **demander** formule une requête : l'autre peut refuser. **exiger** impose une obligation : refuser est difficile, voire impossible.

## Verbe + que

### Que + indicatif

> Le verbe présente un **fait** : on le sait, on le dit, on le pense, on l'espère.

| Verbe                                         | Exemple                                       |
| --------------------------------------------- | --------------------------------------------- |
| dire, affirmer, déclarer que                  | Il dit qu'il viendra.                         |
| annoncer, expliquer, répondre que             | Le ministre annonce que la loi sera votée.    |
| savoir, apprendre que                         | J'ai appris qu'il avait démissionné.          |
| penser, croire, trouver que                   | Je pense que c'est une bonne idée.            |
| être sûr, certain, convaincu que              | Je suis sûr qu'il a raison.                   |
| espérer que                                   | J'espère que tu vas bien.                     |
| il me semble que                              | Il me semble que tu as maigri.                |
| il paraît que                                 | Il paraît qu'il va neiger.                    |
| il est clair, évident, certain, vrai que      | Il est évident que la situation a changé.     |
| il est probable que                           | Il est probable qu'il pleuvra.                |
| se rendre compte, s'apercevoir, constater que | Je me rends compte que j'ai oublié mes clés.  |
| se douter que                                 | Je me doutais qu'il viendrait.                |
| se souvenir que                               | Je me souviens qu'il pleuvait.                |
| s'assurer que                                 | Assurez-vous que la porte est fermée.         |
| promettre que                                 | Je te promets que je serai là.                |
| supposer, imaginer que                        | J'imagine que tu es fatigué.                  |
| décider que                                   | On a décidé que la réunion aurait lieu lundi. |

### Que + subjonctif

> Le verbe présente une **idée** : on la veut, on la craint, on la juge ou on en doute.

| Verbe                     | Exemple                                                    |
| ------------------------- | ---------------------------------------------------------- |

| souhaiter, désirer que    | Je souhaite que tout se passe bien.                        |
| aimer que, j'aimerais que | J'aimerais que tu m'appelles.                              |
| préférer que              | Je préfère que tu restes.                                  |
| demander, exiger que      | Le directeur exige que le rapport soit prêt lundi.         |
| proposer, suggérer que    | Je propose que nous en parlions demain.                    |
| accepter, refuser que     | Il refuse que ses enfants aient un téléphone.              |
| permettre que             | Je ne permettrai pas que tu partes seul.                   |
| attendre que              | J'attends que tu sois prêt.                                |
| s'attendre à ce que       | Je ne m'attendais pas à ce qu'il réagisse ainsi.           |

## Conjonctions

> Chaque conjonction impose son mode. Quand le sujet ne change pas, on emploie souvent la préposition et l'infinitif.

| Sens        | + indicatif                                        | + subjonctif                                  | Même sujet                           |
| ----------- | -------------------------------------------------- | --------------------------------------------- | ------------------------------------ |
| But         | —                                                  | pour que, afin que                            | pour, afin de + inf.                 |
| Crainte     | —                                                  | de peur que (ne), de crainte que (ne)         | de peur de + inf.                    |
| Avant       | —                                                  | avant que (ne)                                | avant de + inf.                      |
| Après       | après que                                          | —                                             | après + inf. passé                   |
| Limite      | —                                                  | jusqu'à ce que                                | jusqu'à + nom                        |
| Attente     | —                                                  | en attendant que                              | en attendant de + inf.               |
| Temps       | quand, lorsque, pendant que, dès que, depuis que   | —                                             | en + participe présent               |
| Concession  | même si, alors que, tandis que                     | bien que, quoique                             | malgré + nom, avoir beau + inf.      |
| Condition   | si, sauf si                                        | à condition que, pourvu que, à moins que (ne) | à condition de, à moins de + inf.    |
| Manière     | —                                                  | sans que                                      | sans + inf.                          |
| Cause       | parce que, puisque, comme, vu que, étant donné que | non que (soutenu)                             | à force de + inf., pour + inf. passé |
| Conséquence | si bien que, de sorte que, au point que            | trop... pour que, assez... pour que           | trop... pour, assez... pour + inf.   |
| Indéfini    | —                                                  | quel que soit, quoi que, qui que, où que      | —                                    |

- À moins que vous (n')habitiez en Amérique du Nord, vous trouverez facilement des transports en commun en ville.
- Sauf si vous habitez en Amérique du Nord, vous trouverez facilement des transports en commun en ville.
- À moins d'habiter en Amérique du Nord, vous trouverez facilement des transports en commun en ville.
- Allons-y, à moins que vous (ne) vouliez vous reposer.
- Je resterai jusqu'à ce que tu reviennes.
- Quel que soit le résultat, je suis fier de toi.

> Après **même si**, comme après **si**, jamais de subjonctif, de futur ni de conditionnel : Même s'il pleut demain, on sortira.

> **au cas où** est suivi du **conditionnel** : Prends un parapluie au cas où il pleuvrait.

> Le **ne** explétif, entre parenthèses ci-dessus, est soutenu et facultatif. Il n'a aucun sens négatif.

### from someone : à qqn

> Avec ces verbes, la personne à qui l'on prend quelque chose est introduite par **à**, et non par **de**.

| Français             | Anglais              | Exemple                             |
| -------------------- | -------------------- | ----------------------------------- |
| emprunter qqch à qqn | to borrow from       | J'ai emprunté un livre à Marie.     |
| acheter qqch à qqn   | to buy from (or for) | J'ai acheté ma voiture à un voisin. |
| voler qqch à qqn     | to steal from        | On lui a volé son portefeuille.     |
| prendre qqch à qqn   | to take from         | Il m'a pris mon stylo.              |
| cacher qqch à qqn    | to hide from         | Elle cache la vérité à ses parents. |
| enlever qqch à qqn   | to take away from    | On lui a enlevé son permis.         |

> **acheter qqch à qqn** peut vouloir dire « from » ou « for » : seul le contexte tranche.

> Pour un objet, **from** se traduit parfois par **dans** ou **sur** : boire dans un verre (drink from a glass), prendre un livre sur l'étagère (take a book from the shelf), copier sur son voisin (copy from one's neighbour).

## Pièges fréquents

| À éviter                              | Correct                                              | Pourquoi                        |
| ------------------------------------- | ---------------------------------------------------- | ------------------------------- |
| J'espère qu'il vienne.                | J'espère qu'il viendra.                              | espérer + indicatif             |
| Je veux que je parte.                 | Je veux partir.                                      | même sujet → infinitif          |
| Je pense qu'il soit malade.           | Je pense qu'il est malade.                           | penser que + indicatif          |
| Je ne pense pas qu'il est malade.     | Je ne pense pas qu'il soit malade.                   | à la négation → subjonctif      |
| Bien qu'il est tard...                | Bien qu'il soit tard...                              | bien que + subjonctif           |
| Même s'il soit tard...                | Même s'il est tard...                                | même si + indicatif             |
| Si j'aurais su...                     | Si j'avais su...                                     | jamais de conditionnel après si |
| Après qu'il soit parti...             | Après qu'il est parti...                             | après que + indicatif           |
| malgré qu'il pleuve                   | bien qu'il pleuve                                    | malgré + nom                    |
| C'est de ça dont je parle.            | C'est de ça que je parle.                            | dont contient déjà de           |
| Cet article s'agit de...              | Cet article parle de... / Il s'agit de...            | s'agir de est impersonnel       |
| J'attends pour le bus.                | J'attends le bus.                                    | attendre + COD                  |
| Je suis obligé à partir.              | Je suis obligé de partir.                            | être obligé de                  |
| Je suis intéressé dans l'histoire.    | Je m'intéresse à l'histoire.                         | s'intéresser à                  |
| Ils s'opposent de ce projet.          | Ils s'opposent à ce projet.                          | s'opposer à                     |
| Je me rappelle de ce jour.            | Je me rappelle ce jour. / Je me souviens de ce jour. | se rappeler + COD               |
| pallier à un problème                 | pallier un problème                                  | pallier + COD                   |
| Il m'a demandé à venir.               | Il m'a demandé de venir.                             | demander à qqn de               |
| Je lui pense.                         | Je pense à lui.                                      | penser à + pronom tonique       |
| Il est facile à comprendre, ce texte. | Ce texte est facile à comprendre.                    | il est + adjectif + de          |
