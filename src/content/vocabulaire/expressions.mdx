# Les expressions du français

## Liens utiles

- [Recherche d'expressions sur Larousse](https://www.larousse.fr/dictionnaires/francais-monolingue)

## Les expressions courantes

| Expression            | Situation                                      |
| --------------------- | ---------------------------------------------- |
| Bonjour               | pour saluer quelqu'un                          |
| Salut                 | pour saluer de manière familière               |
| Au revoir             | quand on quitte quelqu'un                      |
| À bientôt             | quand on pense revoir quelqu'un prochainement  |
| S'il vous plaît       | pour demander quelque chose poliment           |
| Merci                 | pour remercier                                 |
| De rien               | pour répondre à un remerciement                |
| Excusez-moi           | pour attirer l'attention ou s'excuser poliment |
| Désolé(e)             | pour présenter ses excuses                     |
| Oui                   | pour répondre positivement                     |
| Non                   | pour répondre négativement                     |
| Je ne sais pas        | quand on n'a pas la réponse                    |
| Je comprends          | quand une idée est claire                      |
| Je ne comprends pas   | quand une idée n'est pas claire                |
| C'est combien ?       | pour demander le prix                          |
| Où est… ?             | pour demander un lieu                          |
| Je voudrais…          | pour demander quelque chose poliment           |
| Quelle heure est-il ? | pour demander l'heure                          |
| Pouvez-vous m'aider ? | pour demander de l'aide                        |
| Je suis perdu(e)      | quand on ne sait plus où l'on est              |
| Je t'aime             | pour exprimer l'amour                          |
| À demain              | quand on pense revoir quelqu'un le lendemain   |

## Phrases de survie

### Quand on est pressé ou en difficulté

- Je suis en retard.
- Je suis perdu(e).
- Pouvez-vous m'aider ?

### Pour donner une réaction simple

- C'est bon.
- C'est cher !
- Ça va ?
- Ça va !

### Quand on ne comprend pas

- Je ne parle pas bien français.
- Je ne comprends pas.
- Pouvez-vous répéter, s'il vous plaît ?
- Que veut dire « … » ?
- Comment dit-on « … » en français ?

### Pour demander quelque chose

- Où sont les toilettes ?
- C'est combien ?
- Je voudrais…, s'il vous plaît.

### Pour parler de ses sensations

- J'ai faim.
- J'ai soif.
- J'ai chaud.
- J'ai froid.
