# Les expressions du français

## Liens utiles

- [Recherche d'expressions sur Larousse](https://www.larousse.fr/dictionnaires/francais-monolingue)

> Les tableaux suivent l'ordre d'un échange réel (saluer, demander, répondre) plutôt que l'ordre alphabétique. Seules les expressions idiomatiques, qui n'ont pas d'ordre naturel, sont classées de A à Z.

## Salutations et prise de congé

| Expression       | Situation                                          |
| ---------------- | -------------------------------------------------- |
| Bonjour          | pour saluer quelqu'un dans la journée              |
| Bonsoir          | pour saluer quelqu'un le soir                      |
| Salut            | pour saluer de manière familière                   |
| Enchanté(e)      | quand on rencontre quelqu'un pour la première fois |
| Au revoir        | quand on quitte quelqu'un                          |
| À bientôt        | quand on pense revoir quelqu'un prochainement      |
| À tout à l'heure | quand on va revoir quelqu'un dans la journée       |
| À demain         | quand on pense revoir quelqu'un le lendemain       |
| Bonne journée    | pour souhaiter une bonne suite de journée          |
| Bonne soirée     | pour souhaiter une bonne fin de journée            |

## Politesse

| Expression      | Situation                                          |
| --------------- | -------------------------------------------------- |
| S'il vous plaît | pour demander quelque chose poliment               |
| S'il te plaît   | même usage, de manière familière                   |
| Merci           | pour remercier                                     |
| Merci beaucoup  | pour remercier avec insistance                     |
| De rien         | pour répondre à un remerciement                    |
| Je vous en prie | pour répondre à un remerciement, de façon soutenue |
| Excusez-moi     | pour attirer l'attention ou s'excuser poliment     |
| Pardon          | pour s'excuser brièvement ou faire répéter         |
| Désolé(e)       | pour présenter ses excuses                         |
| Avec plaisir    | pour accepter volontiers                           |

## Présentation de soi

| Expression                       | Situation                                    |
| -------------------------------- | -------------------------------------------- |
| Je m'appelle...                  | pour donner son nom                          |
| J'ai ... ans                     | pour donner son âge                          |
| Je viens de...                   | pour indiquer son pays ou sa ville d'origine |
| J'habite à...                    | pour indiquer où l'on vit                    |
| Je travaille comme...            | pour indiquer son métier                     |
| J'apprends le français depuis... | pour situer son apprentissage dans le temps  |
| Je suis ici pour...              | pour expliquer la raison de sa présence      |

## Compréhension et reformulation

| Expression                             | Situation                       |
| -------------------------------------- | ------------------------------- |
| Je comprends                           | quand une idée est claire       |
| Je ne comprends pas                    | quand une idée n'est pas claire |
| Je ne sais pas                         | quand on n'a pas la réponse     |
| Pouvez-vous répéter, s'il vous plaît ? | pour faire répéter              |
| Pouvez-vous parler plus lentement ?    | quand le débit est trop rapide  |
| Que veut dire « ... » ?                | pour demander le sens d'un mot  |
| Comment dit-on « ... » en français ?   | pour demander une traduction    |
| Comment ça s'écrit ?                   | pour demander l'orthographe     |
| Je ne parle pas bien français          | pour signaler son niveau        |

## Demandes et requêtes

| Expression                  | Situation                              |
| --------------------------- | -------------------------------------- |
| Je voudrais...              | pour demander quelque chose poliment   |
| Je cherche...               | pour indiquer ce que l'on veut trouver |
| C'est combien ?             | pour demander le prix                  |
| Où est... ?                 | pour demander un lieu                  |
| Quelle heure est-il ?       | pour demander l'heure                  |
| Pouvez-vous m'aider ?       | pour demander de l'aide                |
| Est-ce que vous auriez... ? | pour demander avec précaution          |

## Opinion

| Expression                  | Situation                                  |
| --------------------------- | ------------------------------------------ |
| À mon avis...               | pour donner son point de vue               |
| Selon moi...                | pour donner son point de vue               |
| D'après moi...              | pour donner son point de vue               |
| Je pense que...             | pour exprimer une opinion                  |
| Je trouve que...            | pour donner une appréciation personnelle   |
| Il me semble que...         | pour exprimer une opinion avec prudence    |
| J'ai l'impression que...    | pour exprimer une opinion incertaine       |
| Personnellement...          | pour marquer que l'avis n'engage que soi   |
| Je suis convaincu(e) que... | pour exprimer une opinion ferme            |
| Il est clair que...         | pour présenter quelque chose comme évident |

## Accord et désaccord

| Expression                 | Situation                                     |
| -------------------------- | --------------------------------------------- |
| Oui                        | pour répondre positivement                    |
| Non                        | pour répondre négativement                    |
| Je suis d'accord           | pour marquer son accord                       |
| Tout à fait                | pour approuver pleinement                     |
| Absolument                 | pour approuver avec force                     |
| Vous avez raison           | pour reconnaître la justesse d'un propos      |
| Je ne suis pas d'accord    | pour marquer son désaccord                    |
| Je ne partage pas cet avis | pour marquer son désaccord, de façon soutenue |
| Au contraire               | pour affirmer l'inverse                       |
| Pas du tout                | pour refuser fermement                        |
| Je crains que non          | pour exprimer un désaccord poli               |

## Nuance et concession

| Expression                     | Situation                                     |
| ------------------------------ | --------------------------------------------- |
| Certes..., mais...             | pour reconnaître un point avant d'objecter    |
| Il est vrai que...             | pour admettre un fait                         |
| Cela dit...                    | pour introduire une réserve                   |
| D'un côté..., de l'autre...    | pour présenter deux aspects opposés           |
| Dans une certaine mesure       | pour limiter la portée de son accord          |
| Ça dépend                      | pour refuser de trancher                      |
| Je ne dirais pas que...        | pour nuancer un jugement                      |
| Il n'en reste pas moins que... | pour maintenir son point malgré la concession |

## Sentiments

| ---------------------- | ------------------------------------------------ |
| Ça me fait plaisir     | pour exprimer sa joie                            |
| Je suis ravi(e) que... | pour exprimer une grande satisfaction            |
| J'ai hâte de...        | pour exprimer une impatience positive            |
| Je t'aime              | pour exprimer l'amour                            |
| Ça ne me dérange pas   | pour indiquer que l'on accepte                   |
| Ça m'inquiète          | pour exprimer une préoccupation                  |
| Je suis déçu(e)        | pour exprimer une déception                      |
| Je regrette que...     | pour exprimer un regret                          |
| Ça m'énerve            | pour exprimer son irritation, de façon familière |

## Courriel et registre formel

| Expression                                  | Situation                                              |
| ------------------------------------------- | ------------------------------------------------------ |
| Madame, Monsieur                            | pour ouvrir un courrier sans connaître le destinataire |
| Je vous écris au sujet de...                | pour annoncer l'objet du message                       |
| Pourriez-vous..., s'il vous plaît ?         | pour formuler une demande polie                        |
| Je vous serais reconnaissant(e) de...       | pour demander de façon très polie                      |
| Je me permets de vous relancer              | pour rappeler une demande restée sans réponse          |
| Dans l'attente de votre réponse             | pour clore avant la formule de politesse               |
| Cordialement                                | formule de clôture courante                            |
| Veuillez agréer mes salutations distinguées | formule de clôture très formelle                       |

## Phrases de survie

### Urgence et difficulté

- Je suis en retard.
- Je suis perdu(e).
- Pouvez-vous m'aider ?

### Réactions courtes

- C'est bon.
- C'est cher !
- Ça va ?
- Ça va !

### Blocages de langue

- Je ne parle pas bien français.
- Je ne comprends pas.
- Pouvez-vous répéter, s'il vous plaît ?
- Que veut dire « ... » ?
- Comment dit-on « ... » en français ?

### Achats et renseignements

- Où sont les toilettes ?
- C'est combien ?
- Je voudrais..., s'il vous plaît.

### Sensations et besoins

- J'ai faim.
- J'ai soif.
- J'ai chaud.
- J'ai froid.
