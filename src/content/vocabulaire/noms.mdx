# Les noms du français

## Liens utiles

- [Recherche de noms sur Larousse](https://www.larousse.fr/dictionnaires/francais-monolingue)

## Pronoms personnels

| Pronom      | Usage simple                                                                      |
| ----------- | --------------------------------------------------------------------------------- |
| je          | pour parler de soi                                                                |
| tu          | pour parler à une personne que l'on tutoie                                        |
| il          | pour parler d'un homme ou d'un nom masculin                                       |
| elle        | pour parler d'une femme ou d'un nom féminin                                       |
| nous        | pour parler de soi avec d'autres personnes                                        |
| vous        | pour parler à plusieurs personnes ou à une personne que l'on vouvoie              |
| ils         | pour parler de plusieurs personnes ou choses, au masculin ou dans un groupe mixte |
| elles       | pour parler de plusieurs personnes ou choses, au féminin                          |
| moi         | forme utilisée pour insister ou après certaines prépositions                      |
| lui / elle  | pour désigner une personne                                                        |
| nous        | pour désigner un groupe qui comprend la personne qui parle                        |
| eux / elles | pour désigner plusieurs personnes                                                 |
| soi         | pour parler d'une personne de manière générale                                    |

---

## Pronoms relatifs

| Pronom  | Usage simple                                        | Exemple                                      |
| ------- | --------------------------------------------------- | -------------------------------------------- |
| qui     | remplace le sujet du verbe qui suit                 | La personne qui parle est ma collègue.       |
| que     | remplace le complément d'objet direct               | Le livre que je lis est passionnant.         |
| dont    | remplace un complément introduit par « de »         | Le film dont je t'ai parlé sort demain.      |
| où      | remplace un complément de lieu ou de temps          | La ville où je suis né a beaucoup changé.    |
| lequel  | s'emploie après une préposition, et s'accorde       | Le dossier sur lequel je travaille est long. |
| ce qui  | reprend une idée entière, en fonction de sujet      | Il a refusé, ce qui m'a surpris.             |
| ce que  | reprend une idée entière, en fonction de complément | Je ne comprends pas ce que tu veux dire.     |
| ce dont | reprend une idée entière, avec « de »               | Voilà ce dont j'avais besoin.                |
