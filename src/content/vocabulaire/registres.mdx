# Les registres de langue

## Liens utiles

- [Recherche de mots sur Larousse](https://www.larousse.fr/dictionnaires/francais-monolingue)

## Repères

- **Familier** : entre amis, en famille, surtout à l'oral. À éviter à l'écrit et à l'examen.
- **Courant** : la langue neutre de tous les jours.
- **Soutenu** : à l'écrit, dans les discours, les lettres formelles et les essais.

> Les documents oraux authentiques contiennent souvent du français familier : il faut savoir le **comprendre**, même si on ne l'emploie pas à l'écrit.

## L'oral familier

- **ne** disparaît : Je sais pas. / C'est pas grave.
- **on** remplace **nous** : On y va ?
- Des sons disparaissent : t'as (tu as), j'sais pas, y a (il y a), p'tit
- Les questions se font par l'intonation : Tu viens ?
- **ça** remplace **cela** : Ça me plaît.
- Les mots sont raccourcis : la télé, l'ordi, le resto, la fac, l'appart, d'acc
- Le **verlan** inverse les syllabes : une meuf (femme), ouf (fou), chelou (louche), relou (lourd), une teuf (fête)

## Écrire en registre soutenu

> À l'écrit, on remplace les verbes et les mots trop généraux par des mots plus précis.

| Courant     | Soutenu                          |
| ----------- | -------------------------------- |
| il y a      | il existe                        |
| avoir       | posséder / disposer de           |
| faire       | réaliser / effectuer             |
| dire        | affirmer / déclarer              |
| donner      | accorder / fournir               |
| montrer     | démontrer / révéler              |
| mettre      | placer / instaurer               |
| voir        | constater / observer             |
| beaucoup de | de nombreux / un grand nombre de |
| aussi       | également                        |
| mais        | cependant / toutefois            |
| après       | ensuite / par la suite           |
| parce que   | car / étant donné que            |
| à cause de  | en raison de                     |
| un problème | une difficulté / un enjeu        |
| une chose   | un élément / un aspect           |
