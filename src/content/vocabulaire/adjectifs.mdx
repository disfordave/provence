# Les adjectifs du français

## Liens utiles

- [Recherche d'adjectifs sur Larousse](https://www.larousse.fr/dictionnaires/francais-monolingue)

## Les adjectifs essentiels

| Adjectif                                | Contraire          | Exemple                        |
| --------------------------------------- | ------------------ | ------------------------------ |
| grand                                   | petit              | Cette maison est grande.       |
| petit                                   | grand              | Le sac est petit.              |
| bon                                     | mauvais            | Ce café est bon.               |
| mauvais                                 | bon                | Le temps est mauvais.          |
| beau / belle                            | laid / laide       | Cette ville est belle.         |
| vieux / vieille                         | jeune              | Cet immeuble est vieux.        |
| nouveau / nouvelle                      | ancien             | J'ai un nouveau téléphone.     |
| chaud                                   | froid              | Le café est chaud.             |
| froid                                   | chaud              | L'eau est froide.              |
| facile                                  | difficile          | Cet exercice est facile.       |
| difficile                               | facile             | Cette question est difficile.  |
| heureux / heureuse / content / contente | triste             | Je suis content aujourd'hui.   |
| triste                                  | heureux / heureuse | Elle est triste.               |
| fort / forte                            | faible             | Il est très fort.              |
| fatigué / fatiguée                      | reposé / reposée   | Je suis fatigué.               |
| occupé / occupée                        | libre              | Je suis occupé cet après-midi. |
| long / longue                           | court / courte     | Le film est long.              |
| court / courte                          | long / longue      | Le trajet est court.           |
