## Place et changement de sens

> La plupart des adjectifs se placent après le nom. Quelques-uns changent complètement de sens selon leur position : c'est un point souvent évalué au niveau B2.

| Adjectif  | Avant le nom                         | Après le nom                             |
| --------- | ------------------------------------ | ---------------------------------------- |
| ancien    | un ancien élève (qui ne l'est plus)  | un livre ancien (qui a beaucoup d'âge)   |
| certain   | un certain succès (un peu de succès) | un succès certain (assuré)               |
| cher      | un cher ami (que l'on aime)          | un repas cher (qui coûte beaucoup)       |
| curieux   | un curieux personnage (étrange)      | un enfant curieux (qui veut savoir)      |
| dernier   | la dernière semaine (la finale)      | la semaine dernière (celle d'avant)      |
| différent | différentes raisons (plusieurs)      | des raisons différentes (qui s'opposent) |
| grand     | un grand homme (illustre)            | un homme grand (de haute taille)         |
| même      | le même jour (identique)             | le jour même (précisément celui-là)      |
| pauvre    | un pauvre homme (que l'on plaint)    | un homme pauvre (qui n'a pas d'argent)   |
| propre    | ma propre voiture (la mienne)        | une voiture propre (qui a été nettoyée)  |
| seul      | un seul homme (un unique homme)      | un homme seul (sans compagnie)           |
| simple    | un simple employé (rien de plus)     | un exercice simple (facile)              |
| vrai      | un vrai problème (un problème réel)  | une histoire vraie (conforme aux faits)  |

## Féminin

| Terminaison au masculin | Féminin         | Exemple                                                       |
| ----------------------- | --------------- | ------------------------------------------------------------- |
| cas général             | + e             | grand → grande                                                |
| -e                      | forme inchangée | simple → simple                                               |
| -er                     | -ère            | cher → chère                                                  |
| -eux                    | -euse           | heureux → heureuse                                            |
| -f                      | -ve             | actif → active                                                |
| -el, -eil               | -elle, -eille   | naturel → naturelle                                           |
| -en, -on                | -enne, -onne    | ancien → ancienne ; bon → bonne                               |
| -et                     | -ette ou -ète   | muet → muette ; complet → complète                            |
| -eur                    | -euse ou -rice  | travailleur → travailleuse ; créateur → créatrice             |
| -c                      | -che ou -que    | blanc → blanche ; public → publique                           |
| irréguliers             | à mémoriser     | beau → belle ; vieux → vieille ; doux → douce ; long → longue |
