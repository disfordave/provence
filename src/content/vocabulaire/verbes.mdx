## Les verbes essentiels

| Verbe           | Idée simple                                                | Exemple                  |
| --------------- | ---------------------------------------------------------- | ------------------------ |
| être            | exprimer un état ou une identité                           | Je suis fatigué.         |
| avoir           | posséder ou exprimer certaines sensations                  | J'ai un chat.            |
| aller           | se déplacer vers un lieu                                   | Je vais à Paris.         |
| faire           | réaliser une action                                        | Je fais du sport.        |
| dire            | exprimer quelque chose avec des mots                       | Je dis la vérité.        |
| voir            | regarder ou percevoir avec les yeux                        | Je vois un ami.          |
| savoir          | connaître une information ou un fait                       | Je sais la réponse.      |
| connaître       | être familier avec une personne, un lieu ou une chose      | Je connais Marie.        |
| venir           | se déplacer vers l'endroit où l'on parle                   | Je viens demain.         |
| vouloir         | exprimer un désir                                          | Je veux du café.         |
| pouvoir         | avoir la possibilité ou la capacité de faire quelque chose | Je peux parler français. |
| devoir          | exprimer une obligation                                    | Je dois partir.          |
| prendre         | saisir, utiliser ou consommer quelque chose                | Je prends le bus.        |
| mettre          | placer quelque chose ou s'habiller avec quelque chose      | Je mets une veste.       |
| trouver         | découvrir ou avoir une opinion sur quelque chose           | Je trouve ça bien.       |
| donner          | offrir ou transmettre quelque chose                        | Je donne un cadeau.      |
| parler          | utiliser la parole ou une langue                           | Je parle français.       |
| manger          | prendre de la nourriture                                   | Je mange une pomme.      |
| boire           | prendre un liquide                                         | Je bois de l'eau.        |
| vivre           | être en vie ou habiter quelque part                        | Je vis à Lyon.           |
| aimer           | apprécier ou ressentir de l'affection                      | J'aime le chocolat.      |
| penser          | avoir une idée ou une opinion                              | Je pense que oui.        |
| demander        | poser une question ou solliciter quelque chose             | Je demande le chemin.    |
| utiliser        | se servir de quelque chose                                 | J'utilise mon téléphone. |
| travailler      | exercer une activité ou un métier                          | Je travaille ici.        |
| avoir besoin de | exprimer une nécessité                                     | J'ai besoin d'aide.      |
| dormir          | se reposer pendant le sommeil                              | Je dors bien.            |
| écrire          | produire des mots avec des lettres                         | J'écris une lettre.      |
| lire            | comprendre un texte écrit                                  | Je lis un livre.         |
