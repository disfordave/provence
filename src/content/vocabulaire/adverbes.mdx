## Les adverbes de temps

| Adverbe        | Idée simple                         | Exemple                                   |
| -------------- | ----------------------------------- | ----------------------------------------- |
| actuellement   | en ce moment                        | Il est actuellement en réunion.           |
| aujourd'hui    | le jour où l'on est                 | Aujourd'hui, je reste chez moi.           |
| auparavant     | avant ce moment                     | Il faut auparavant remplir ce formulaire. |
| aussitôt       | immédiatement après                 | Il est parti aussitôt.                    |
| autrefois      | dans un passé lointain              | Autrefois, on écrivait des lettres.       |
| bientôt        | dans peu de temps                   | Le film commence bientôt.                 |
| déjà           | avant le moment présent             | J'ai déjà vu ce film.                     |
| demain         | le jour après aujourd'hui           | Demain, je pars très tôt.                 |
| désormais      | à partir de maintenant              | Désormais, le magasin ferme à 19 heures.  |
| enfin          | après une attente                   | Enfin, nous y sommes arrivés.             |
| entre-temps    | pendant ce temps-là                 | Entre-temps, la situation a changé.       |
| hier           | le jour avant aujourd'hui           | Hier, il a plu toute la journée.          |
| immédiatement  | tout de suite                       | Répondez-moi immédiatement.               |
| longtemps      | pendant une longue durée            | Il a longtemps hésité.                    |
| maintenant     | à ce moment précis                  | Je pars maintenant.                       |
| plus tard      | après le moment présent             | On en reparlera plus tard.                |
| récemment      | il y a peu de temps                 | Il a récemment changé de poste.           |
| tard           | après l'heure habituelle            | Il est rentré très tard.                  |
| tôt            | avant l'heure habituelle            | Je me lève tôt en semaine.                |
| tout à l'heure | dans un moment, ou il y a un moment | Je te rappelle tout à l'heure.            |

## Les connecteurs logiques

> Ce sont les mots qui articulent un raisonnement : ils sont attendus à l'écrit comme à l'oral au niveau B2. Le tableau suit l'ordre d'un développement plutôt que l'ordre alphabétique.

| Connecteur      | Rôle                                | Exemple                                               |
| --------------- | ----------------------------------- | ----------------------------------------------------- |
| d'abord         | ouvrir une énumération              | D'abord, présentons le contexte.                      |
| ensuite         | poursuivre une énumération          | Ensuite, nous verrons les conséquences.               |
| et              | ajouter une information             | Il est venu et il est reparti aussitôt.               |
| de plus         | ajouter un argument                 | De plus, le prix a beaucoup augmenté.                 |
| en outre        | ajouter un argument (soutenu)       | En outre, le délai est trop court.                    |
| par ailleurs    | ajouter un point nouveau            | Par ailleurs, il faut prévoir un budget.              |
| également       | ajouter un élément semblable        | Il faut également prévenir la mairie.                 |
| mais            | marquer une opposition              | C'est cher, mais vraiment utile.                      |
| en revanche     | marquer un contraste                | En revanche, le service est excellent.                |
| au contraire    | marquer l'inverse                   | Au contraire, cela m'arrange.                         |
| alors que       | opposer deux situations             | Il dort alors que les autres travaillent.             |
| or              | introduire un fait qui relance      | Or, rien n'a été fait depuis.                         |
| cependant       | nuancer ce qui précède              | C'est risqué ; cependant, il faut essayer.            |
| pourtant        | marquer une contradiction           | Il a pourtant tout essayé.                            |
| néanmoins       | nuancer (soutenu)                   | Le projet est ambitieux, néanmoins réalisable.        |
| toutefois       | nuancer (soutenu)                   | Toutefois, une réserve s'impose.                      |
| certes... mais  | concéder avant de réfuter           | Certes, c'est difficile, mais pas impossible.         |
| bien que        | concéder (+ subjonctif)             | Bien qu'il soit tard, il continue.                    |
| même si         | concéder (+ indicatif)              | Même s'il pleut, nous sortirons.                      |
| car             | donner une cause                    | Il est resté car il pleuvait.                         |
| parce que       | donner une cause                    | Je pars parce que je suis fatigué.                    |
| puisque         | donner une cause déjà connue        | Puisque tu insistes, j'accepte.                       |
| comme           | donner une cause, en tête de phrase | Comme il pleuvait, nous sommes rentrés.               |
| en effet        | confirmer et expliquer              | Il est absent ; en effet, il est malade.              |
| donc            | tirer une conséquence               | Il pleut, donc je reste ici.                          |
| alors           | tirer une conséquence               | Il n'y avait plus de place, alors nous sommes partis. |
| ainsi           | tirer une conséquence               | Ainsi, le problème est résolu.                        |
| par conséquent  | tirer une conséquence (soutenu)     | Par conséquent, la séance est reportée.               |
| c'est pourquoi  | expliciter une conséquence          | C'est pourquoi nous avons changé d'avis.              |
| si bien que     | marquer un résultat                 | Il a plu, si bien que le match a été annulé.          |
| pour que        | exprimer un but (+ subjonctif)      | Je t'écris pour que tu sois informé.                  |
| si              | poser une condition                 | Si tu veux, on peut y aller ensemble.                 |
| à condition que | poser une condition (+ subjonctif)  | J'accepte à condition que ce soit clair.              |
| sinon           | envisager le cas contraire          | Dépêche-toi, sinon nous serons en retard.             |
| par exemple     | illustrer                           | Certains fruits, par exemple les agrumes.             |
| notamment       | citer un cas parmi d'autres         | Plusieurs pays, notamment la France.                  |
| c'est-à-dire    | reformuler                          | Le niveau B2, c'est-à-dire un niveau avancé.          |
| autrement dit   | reformuler                          | Autrement dit, c'est impossible.                      |
| en résumé       | résumer                             | En résumé, le bilan reste positif.                    |
| finalement      | marquer l'issue                     | Finalement, il a accepté.                             |
| enfin           | clore une énumération               | Enfin, nous conclurons sur ce point.                  |
| en conclusion   | conclure                            | En conclusion, il faut agir vite.                     |

## La formation des adverbes en -ment

| Cas                          | Règle                             | Exemple                                   |
| ---------------------------- | --------------------------------- | ----------------------------------------- |
| cas général                  | féminin de l'adjectif + **-ment** | lent → lente → lentement                  |
| adjectif masculin en voyelle | masculin + **-ment**              | vrai → vraiment ; poli → poliment         |
| adjectif en **-ant**         | **-amment**                       | courant → couramment                      |
| adjectif en **-ent**         | **-emment**                       | évident → évidemment                      |
| quelques irréguliers         | à mémoriser                       | précis → précisément ; gentil → gentiment |

> Attention : **-amment** et **-emment** se prononcent tous les deux [amɑ̃].

## Les mots interrogatifs

| Mot                                       | Usage                                                              | Exemple                                                    |
| ----------------------------------------- | ------------------------------------------------------------------ | ---------------------------------------------------------- |
| que / qu' / quoi                          | demander une chose ou une action                                   | _Que fais-tu ?_ / _Tu veux quoi ?_                         |
| quel / quelle / quels / quelles           | choisir ou identifier parmi plusieurs possibilités                 | _Quel jour sommes-nous ?_ / _Quelle couleur préfères-tu ?_ |
| qui                                       | demander l'identité d'une personne                                 | _Qui est là ?_                                             |
| où                                        | demander un lieu                                                   | _Où habites-tu ?_                                          |
| quand                                     | demander un moment                                                 | _Quand est-ce que tu pars ?_                               |
| pourquoi                                  | demander une raison                                                | _Pourquoi tu ris ?_                                        |
| comment                                   | demander la manière ou l'état                                      | _Comment ça va ?_                                          |
| combien / combien de                      | demander une quantité ou un prix                                   | _Combien ça coûte ?_ / _Combien de frères as-tu ?_         |
| lequel / laquelle / lesquels / lesquelles | demander de choisir un élément précis                              | _Lequel préfères-tu ?_                                     |
| à qui / de qui                            | demander à quelle personne quelque chose appartient ou se rapporte | _À qui est ce livre ?_                                     |
