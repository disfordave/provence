## Les expressions de temps

| Expression | Idée simple                               |
| ---------- | ----------------------------------------- |
| maintenant | à ce moment précis                        |
| bientôt    | dans peu de temps                         |
| plus tard  | après le moment présent                   |
| tôt        | avant l'heure habituelle                  |
| tard       | après l'heure habituelle                  |
| toujours   | à chaque fois ou continuellement          |
| jamais     | à aucun moment                            |
| souvent    | de nombreuses fois                        |
| parfois    | certaines fois                            |
| d'habitude | généralement                              |
| encore     | une nouvelle fois ou toujours à ce moment |

## Les mots de liaison

| Mot       | Idée simple                                       |
| --------- | ------------------------------------------------- |
| et        | ajoute une information                            |
| mais      | marque une opposition                             |
| ou        | présente un choix                                 |
| parce que | donne une raison                                  |
| donc      | présente une conséquence                          |
| cependant | marque une opposition ou une nuance               |
| alors     | introduit une conséquence, une suite ou un moment |
| si        | introduit une condition                           |
| quand     | parle du moment                                   |
| où        | parle du lieu                                     |
| pourquoi  | demande ou explique une raison                    |
| comment   | parle de la manière                               |
| que / qui | relie des éléments dans une phrase                |
| aussi     | ajoute une information similaire                  |
| très      | renforce un adjectif ou un adverbe                |
| plus      | indique une quantité ou une intensité supérieure  |
| moins     | indique une quantité ou une intensité inférieure  |

## Les mots interrogatifs

| Mot                                       | Usage                                                              | Exemple                                                    |
| ----------------------------------------- | ------------------------------------------------------------------ | ---------------------------------------------------------- |
| que / qu' / quoi                          | demander une chose ou une action                                   | _Que fais-tu ?_ / _Tu veux quoi ?_                         |
| quel / quelle / quels / quelles           | choisir ou identifier parmi plusieurs possibilités                 | _Quel jour sommes-nous ?_ / _Quelle couleur préfères-tu ?_ |
| qui                                       | demander l'identité d'une personne                                 | _Qui est là ?_                                             |
| où                                        | demander un lieu                                                   | _Où habites-tu ?_                                          |
| quand                                     | demander un moment                                                 | _Quand est-ce que tu pars ?_                               |
| pourquoi                                  | demander une raison                                                | _Pourquoi tu ris ?_                                        |
| comment                                   | demander la manière ou l'état                                      | _Comment ça va ?_                                          |
| combien / combien de                      | demander une quantité ou un prix                                   | _Combien ça coûte ?_ / _Combien de frères as-tu ?_         |
| lequel / laquelle / lesquels / lesquelles | demander de choisir un élément précis                              | _Lequel préfères-tu ?_                                     |
| à qui / de qui                            | demander à quelle personne quelque chose appartient ou se rapporte | _À qui est ce livre ?_                                     |
