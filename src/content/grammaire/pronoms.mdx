# Déterminants et pronoms

## Repères

- **Déterminant** : accompagne un nom et le détermine.
- **Pronom** : remplace généralement un nom, un groupe nominal ou une idée.
- **Genre** : masculin / féminin
- **Nombre** : singulier / pluriel

**Exemple :**

> **mon** livre → déterminant possessif

> le **mien** → pronom possessif

> **ce** livre → déterminant démonstratif

> **celui-ci** → pronom démonstratif

---

## Déterminants

### Articles

#### Les articles définis

> le / la / l' / les

|           | Masculin | Féminin |
| --------- | -------- | ------- |
| Singulier | le / l'  | la / l' |
| Pluriel   | les      | les     |

**Exemples :**

- le livre
- la maison
- l'homme
- l'école
- les enfants

L'article défini peut désigner quelque chose de précis ou une catégorie en général.

> J'aime **le café**.

> **Les chats** sont indépendants.

---

#### Les articles indéfinis

> un / une / des

|           | Masculin | Féminin |
| --------- | -------- | ------- |
| Singulier | un       | une     |
| Pluriel   | des      | des     |

**Exemples :**

- un livre
- une maison
- des amis

##### un / une / des → de à la négation

À la négation, **un / une / des** deviennent généralement **de / d'**.

> J'ai **une** voiture.

> Je n'ai pas **de** voiture.

> Il y a **des** places.

> Il n'y a pas **de** places.

Avec **être**, l'article est généralement conservé.

> Ce n'est pas **une** erreur.

##### des → de devant un adjectif

Devant un adjectif placé avant un nom pluriel, **des** devient généralement **de**.

> des livres intéressants

> de grands livres

---

#### Les articles partitifs

> du / de la / de l'

Ils expriment généralement une quantité non comptée.

| Masculin | Féminin | Devant voyelle ou h muet |
| -------- | ------- | ------------------------ |
| du       | de la   | de l'                    |

**Exemples :**

- du pain
- de la musique
- de l'eau

À la négation, on emploie généralement **de / d'**.

> Je bois **du café**.

> Je ne bois pas **de café**.

Avec **être**, l'article est généralement conservé.

> Ce n'est pas **du vin**.

> Ce n'est pas **de la bière**.

---

#### Les contractions

##### à + article défini

| Forme   | Contraction |
| ------- | ----------- |
| à + le  | au          |
| à + les | aux         |

> Je vais **au** cinéma.

> Je parle **aux** étudiants.

Il n'y a pas de contraction avec **la** ou **l'**.

> à la maison

> à l'école

##### de + article défini

| Forme    | Contraction |
| -------- | ----------- |
| de + le  | du          |
| de + les | des         |

> Je reviens **du** travail.

> Je parle **des** étudiants.

---

#### Absence d'article

Dans certains emplois, le nom s'utilise sans article.

##### Profession

> Je suis journaliste.

##### Certaines relations

> Ils sont frères.

> Ils sont amis.

##### Certaines expressions

> avoir besoin de temps

> une boîte à outils

---

### Déterminants possessifs

> mon / ma / mes...

Le déterminant possessif s'accorde avec **la chose possédée**, et non avec la personne qui possède.

| Possesseur     | Masculin singulier | Féminin singulier | Pluriel |
| -------------- | ------------------ | ----------------- | ------- |
| je             | mon                | ma                | mes     |
| tu             | ton                | ta                | tes     |
| il / elle / on | son                | sa                | ses     |
| nous           | notre              | notre             | nos     |
| vous           | votre              | votre             | vos     |
| ils / elles    | leur               | leur              | leurs   |

**Exemples :**

- mon livre
- ma voiture
- mes amis
- notre maison
- leurs enfants

Devant une voyelle ou un **h muet**, on emploie **mon / ton / son** devant un nom féminin.

> mon amie

> ton école

> son histoire

et non :

> ~~ma amie~~

---

### Déterminants démonstratifs

> ce / cet / cette / ces

|                                   | Forme |
| --------------------------------- | ----- |
| Masculin singulier                | ce    |
| Masculin devant voyelle ou h muet | cet   |
| Féminin singulier                 | cette |
| Pluriel                           | ces   |

**Exemples :**

- ce livre
- cet homme
- cette maison
- ces enfants

On peut ajouter **-ci** ou **-là** au nom.

> ce livre-ci

> cette maison-là

Avec un **h aspiré**, on emploie **ce**, et non **cet**.

> ce haricot

---

### Déterminants interrogatifs et exclamatifs

> quel / quelle / quels / quelles

|           | Masculin | Féminin |
| --------- | -------- | ------- |
| Singulier | quel     | quelle  |
| Pluriel   | quels    | quelles |

#### Interrogation

> **Quel** livre préfères-tu ?

> **Quelle** heure est-il ?

> **Quels** films regardes-tu ?

#### Exclamation

> **Quelle** surprise !

> **Quel** beau jour !

---

### Déterminants indéfinis

Ils indiquent une quantité, une identité ou une totalité de manière non précise.

| Déterminant                  | Exemple             |
| ---------------------------- | ------------------- |
| chaque                       | chaque jour         |
| quelques                     | quelques minutes    |
| plusieurs                    | plusieurs personnes |
| certains / certaines         | certains étudiants  |
| aucun / aucune               | aucune idée         |
| tout / toute / tous / toutes | toute la journée    |
| autre / autres               | une autre question  |
| même / mêmes                 | la même chose       |

#### chaque

> **chaque** + nom singulier

> Chaque étudiant a un livre.

#### quelques

> **quelques** + nom pluriel

> J'ai quelques questions.

#### plusieurs

> **plusieurs** + nom pluriel

> Plusieurs personnes sont arrivées.

#### aucun

> **aucun / aucune** + nom singulier

> Je n'ai aucune idée.

---

## Pronoms

### Pronoms personnels

#### Pronoms sujets

| Personne                 | Pronom         |
| ------------------------ | -------------- |
| 1<sup>re</sup> singulier | je             |
| 2<sup>e</sup> singulier  | tu             |
| 3<sup>e</sup> singulier  | il / elle / on |
| 1<sup>re</sup> pluriel   | nous           |
| 2<sup>e</sup> pluriel    | vous           |
| 3<sup>e</sup> pluriel    | ils / elles    |

**Exemple :**

> **Je** parle français.

> **Ils** arrivent demain.

En français, le pronom sujet est généralement obligatoire, même lorsque la terminaison du verbe suffirait à indiquer la personne.

> **Il** est tard.

et non :

> ~~Est tard.~~

Il se maintient même dans les réponses les plus brèves.

> **Je** mange.

> **Je** passe.

#### on

**On** se conjugue comme **il / elle**.

> On est prêt.

Dans la langue courante, **on** remplace très souvent **nous**.

> Nous allons au cinéma.

> On va au cinéma.

---

### Pronoms compléments

#### COD

> complément d'objet direct

| Personne    | Pronom |
| ----------- | ------ |
| je          | me     |
| tu          | te     |
| il          | le     |
| elle        | la     |
| nous        | nous   |
| vous        | vous   |
| ils / elles | les    |

**Exemples :**

> Je vois Marie.

> Je **la** vois.

> Je connais Paul et Marie.

> Je **les** connais.

---

#### COI

> complément d'objet indirect

| Personne    | Pronom |
| ----------- | ------ |
| je          | me     |
| tu          | te     |
| il / elle   | lui    |
| nous        | nous   |
| vous        | vous   |
| ils / elles | leur   |

**Exemples :**

> Je parle à Marie.

> Je **lui** parle.

> Je téléphone à mes parents.

> Je **leur** téléphone.

Tous les compléments introduits par **à** ne deviennent cependant pas automatiquement **lui / leur**.

**Exemple :**

> Je pense à Marie.

> Je pense **à elle**.

---

### Pronoms toniques

> moi / toi / lui / elle / soi / nous / vous / eux / elles

| Sujet         | Pronom tonique |
| ------------- | -------------- |
| je            | moi            |
| tu            | toi            |
| il            | lui            |
| elle          | elle           |
| on (indéfini) | soi            |
| nous          | nous           |
| vous          | vous           |
| ils           | eux            |
| elles         | elles          |

Lorsque **on** signifie **nous**, on emploie souvent **nous** comme forme tonique.

> On rentre chez nous.

Ils s'emploient notamment :

#### Après une préposition

> avec **moi**

> pour **elle**

> chez **eux**

#### Pour insister

> **Moi**, je préfère rester ici.

> **Lui**, il ne dit rien.

#### Après c'est

> C'est **moi**.

> C'est **elle**.

---

### Pronoms réfléchis

> me / te / se / nous / vous / se

| Sujet          | Pronom réfléchi |
| -------------- | --------------- |
| je             | me              |
| tu             | te              |
| il / elle / on | se              |
| nous           | nous            |
| vous           | vous            |
| ils / elles    | se              |

Devant une voyelle ou un **h muet** :

> me → m'  
> te → t'  
> se → s'

**Exemple :**

> Je m'appelle...

**Exemples :**

> Je **me** lève.

> Elle **se** prépare.

> Nous **nous** rencontrons demain.

---

### Pronoms adverbiaux

#### y

**y** remplace généralement :

> à + chose

ou un complément de lieu.

**Exemples :**

> Je pense à ce problème.

> J'**y** pense.

> Je vais à Paris.

> J'**y** vais.

Pour une personne, on emploie généralement un pronom tonique lorsque le verbe le demande.

> Je pense à Marie.

> Je pense à **elle**.

---

#### en

**en** remplace généralement :

> de + nom

ou une quantité.

**Exemples :**

> Je parle de ce problème.

> J'**en** parle.

> Je veux du café.

> J'**en** veux.

Avec une quantité, la quantité reste exprimée.

> J'ai trois frères.

> J'**en** ai trois.

> Je bois beaucoup de café.

> J'**en** bois beaucoup.

---

### Ordre des pronoms

Devant un verbe conjugué :

> me / te / se / nous / vous → le / la / les → lui / leur → y → en → verbe

**Exemples :**

> Je donne le livre à Marie.

> Je **le lui** donne.

> Je parle de ce problème à Paul.

> Je **lui en** parle.

> Je me souviens de cette histoire.

> Je **m'en** souviens.

Avec un temps composé, les pronoms se placent devant l'auxiliaire.

> Je **le lui ai** donné.

Devant un infinitif, ils se placent généralement devant l'infinitif dont ils dépendent.

> Je vais **le lui donner**.

---

#### À l'impératif affirmatif

L'ordre change.

> verbe → le / la / les → moi / toi / lui / nous / vous / leur → y → en

**Exemples :**

> Donne-**le-moi** !

> Parle-**lui-en** !

> Vas-**y** !

> Donne-**m'en** !

À l'impératif négatif, on retrouve l'ordre normal.

> Ne **me le** donne pas !

> N'**y** va pas !

---

### Pronoms possessifs

Ils remplacent :

> déterminant possessif + nom

**Exemple :**

> C'est mon livre.

> C'est **le mien**.

| Possesseur     | Masculin singulier | Féminin singulier | Masculin pluriel | Féminin pluriel |
| -------------- | ------------------ | ----------------- | ---------------- | --------------- |
| je             | le mien            | la mienne         | les miens        | les miennes     |
| tu             | le tien            | la tienne         | les tiens        | les tiennes     |
| il / elle / on | le sien            | la sienne         | les siens        | les siennes     |
| nous           | le nôtre           | la nôtre          | les nôtres       | les nôtres      |
| vous           | le vôtre           | la vôtre          | les vôtres       | les vôtres      |
| ils / elles    | le leur            | la leur           | les leurs        | les leurs       |

**Exemples :**

> Mon téléphone est ici. Où est **le tien** ?

> Notre voiture est rouge ; **la leur** est noire.

---

### Pronoms démonstratifs

#### Formes variables

> celui / celle / ceux / celles

|           | Masculin | Féminin |
| --------- | -------- | ------- |
| Singulier | celui    | celle   |
| Pluriel   | ceux     | celles  |

**celui / celle / ceux / celles** sont généralement accompagnés d'un complément ou de **-ci / -là**.

#### Avec -ci / -là

> celui-ci

> celle-là

> ceux-ci

> celles-là

**Exemple :**

> Je préfère cette voiture à **celle-là**.

#### Avec de

> Celui **de Marie** est plus grand.

#### Avec un pronom relatif

> Celui **qui parle** est mon professeur.

> Celle **que tu vois** est ma sœur.

---

### Formes neutres

#### ce

**ce** s'emploie notamment avec **être**.

> C'est intéressant.

> Ce sont mes amis.

Il peut aussi reprendre une idée entière.

> Il a refusé, **ce** qui m'a surpris.

---

#### ceci / cela / ça

> ceci

> cela

> ça

**ça** est très fréquent dans la langue courante.

> **Ça** va ?

> Je n'aime pas **ça**.

> **Cela** dépend.

**ceci** est plus rare dans la langue courante et sert notamment à désigner ce qui est proche ou ce qui va suivre.

---

#### le neutre

**le** peut remplacer une idée, un adjectif ou une proposition.

> Tu sais qu'il vient ?

> Oui, je **le** sais.

> Elle est heureuse ?

> Oui, elle **l'**est.

---

### Pronoms interrogatifs

#### qui

Pour interroger principalement sur une personne.

> **Qui** vient ?

> Avec **qui** travailles-tu ?

---

#### que / qu'

> **Que** fais-tu ?

> **Qu'**est-ce que tu veux ?

Après une préposition, on emploie généralement **quoi**.

> De **quoi** parles-tu ?

> À **quoi** penses-tu ?

---

#### lequel

> lequel / laquelle / lesquels / lesquelles

|           | Masculin | Féminin    |
| --------- | -------- | ---------- |
| Singulier | lequel   | laquelle   |
| Pluriel   | lesquels | lesquelles |

**Exemple :**

> Tu préfères quel livre ?

> **Lequel** préfères-tu ?

---

#### Contractions avec lequel

##### à + lequel

| Forme          | Résultat   |
| -------------- | ---------- |
| à + lequel     | auquel     |
| à + lesquels   | auxquels   |
| à + laquelle   | à laquelle |
| à + lesquelles | auxquelles |

> **Auquel** penses-tu ?

##### de + lequel

| Forme           | Résultat    |
| --------------- | ----------- |
| de + lequel     | duquel      |
| de + lesquels   | desquels    |
| de + laquelle   | de laquelle |
| de + lesquelles | desquelles  |

> Près **duquel** habites-tu ?

---

### Adverbes interrogatifs

> où / quand / comment / pourquoi

**Exemples :**

> Où habites-tu ?

> Quand arrives-tu ?

> Comment ça va ?

> Pourquoi ?

---

### Pronoms relatifs

Ils relient une proposition à un nom ou à une idée.

#### qui

**qui** est généralement sujet du verbe qui suit.

> L'homme **qui parle** est mon professeur.

> Le livre **qui est sur la table** est à moi.

---

#### que / qu'

**que** est généralement COD.

> Le livre **que je lis** est intéressant.

> La personne **qu'il connaît** habite ici.

---

#### dont

**dont** remplace généralement :

> de + nom / personne / chose

**Exemples :**

> Le livre **dont je parle** → parler **de** ce livre

> La femme **dont le fils** habite ici → le fils **de** cette femme

---

#### où

**où** exprime généralement un lieu ou un moment.

> La ville **où j'habite**

> Le jour **où je suis arrivé**

---

#### lequel

> lequel / laquelle / lesquels / lesquelles

Il s'emploie notamment après une préposition, surtout pour des choses.

> La chaise sur **laquelle** je suis assis

> Le projet **auquel** je participe

> La maison près de **laquelle** j'habite

---

#### ce qui / ce que / ce dont

Ils remplacent une idée sans antécédent nominal exprimé.

##### ce qui

> **Ce qui** m'intéresse, c'est la langue.

**ce qui** est sujet.

##### ce que

> Je comprends **ce que** tu veux dire.

**ce que** est COD.

##### ce dont

> Voilà **ce dont** j'ai besoin.

**ce dont** correspond généralement à **de + quelque chose**.

---

### Pronoms indéfinis

Ils désignent une personne, une chose ou une quantité de manière non précise.

| Pronom               | Exemple                    |
| -------------------- | -------------------------- |
| quelqu'un            | Quelqu'un arrive.          |
| quelque chose        | J'ai quelque chose à dire. |
| personne             | Je ne vois personne.       |
| rien                 | Je ne vois rien.           |
| chacun / chacune     | Chacun a son opinion.      |
| certains / certaines | Certains sont partis.      |
| plusieurs            | Plusieurs sont venus.      |
| aucun / aucune       | Aucun ne fonctionne.       |
| tout                 | Tout va bien.              |
| tous / toutes        | Tous sont prêts.           |

#### quelqu'un / personne

> Quelqu'un est là.

> Personne n'est là.

#### quelque chose / rien

> J'ai quelque chose.

> Je n'ai rien.

#### chacun

> Chacun doit choisir.

#### tous / toutes

> Ils sont **tous** là.

> Elles sont **toutes** prêtes.

## COD, COI, y ou en ?

### COD

Pas de préposition.

> Je regarde **le film**.

> Je **le** regarde.

### COI

Souvent :

> à + personne

> Je parle **à Marie**.

> Je **lui** parle.

### y

Souvent :

> à + chose / lieu

> Je pense **à mon travail**.

> J'**y** pense.

### en

Souvent :

> de + chose / quantité

> Je parle **de mon travail**.

> J'**en** parle.
