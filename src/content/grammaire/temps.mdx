# Les temps du français

## Liens utiles

- [Recherche de conjugaison sur NouvelObs](https://la-conjugaison.nouvelobs.com/)

## Repères

- **1<sup>er</sup> groupe** : verbes en **-er**
- **2<sup>e</sup> groupe** : verbes réguliers en **-ir** avec participe présent en **-issant**
- **3<sup>e</sup> groupe** : les autres verbes
- **Sujet** : Je / Tu / Il, Elle, On / Nous / Vous / Ils, Elles
- **Infinitif** : forme non conjuguée du verbe
- **Participe passé** : gagné, fini, vendu, fait, venu...

### Ordre des pronoms

> me / te / se / nous / vous → le / la / les → lui / leur → y → en → verbe

## Présent

### Le présent

> Sujet + présent

**Exemple :** Je gagne un bon salaire.

| Sujet      | 1<sup>er</sup> | 2<sup>e</sup> |
| ---------- | -------------- | ------------- |
| Je         | -e             | -is           |
| Tu         | -es            | -is           |
| Il/Elle/On | -e             | -it           |
| Nous       | -ons           | -issons       |
| Vous       | -ez            | -issez        |
| Ils/Elles  | -ent           | -issent       |

#### Verbes fréquents

| Verbe   | Je    | Tu    | Il/Elle/On | Nous    | Vous   | Ils/Elles |
| ------- | ----- | ----- | ---------- | ------- | ------ | --------- |
| avoir   | ai    | as    | a          | avons   | avez   | ont       |
| être    | suis  | es    | est        | sommes  | êtes   | sont      |
| aller   | vais  | vas   | va         | allons  | allez  | vont      |
| venir   | viens | viens | vient      | venons  | venez  | viennent  |
| faire   | fais  | fais  | fait       | faisons | faites | font      |
| savoir  | sais  | sais  | sait       | savons  | savez  | savent    |
| pouvoir | peux  | peux  | peut       | pouvons | pouvez | peuvent   |
| vouloir | veux  | veux  | veut       | voulons | voulez | veulent   |

## Passé

### Le passé composé

> Sujet + avoir / être (présent) + participe passé

**Exemple :** J'ai gagné le match hier.

| Sujet      | avoir / être   | 1<sup>er</sup> | 2<sup>e</sup> |
| ---------- | -------------- | -------------- | ------------- |
| Je         | ai / suis      | -é             | -i            |
| Tu         | as / es        | -é             | -i            |
| Il/Elle/On | a / est        | -é             | -i            |
| Nous       | avons / sommes | -é             | -i            |
| Vous       | avez / êtes    | -é             | -i            |
| Ils/Elles  | ont / sont     | -é             | -i            |

#### Accord du participe passé

> Avec **être**, le participe passé s'accorde généralement avec le sujet.

- Il est arrivé.
- Elle est arrivée.
- Ils sont arrivés.
- Elles sont arrivées.

> Avec **avoir**, le participe passé s'accorde avec le **COD** seulement si le COD est placé **avant** le verbe.

- J'ai acheté des fleurs. (COD après le verbe → pas d'accord)
- Je les ai achetées. (les = les fleurs)
- Les fleurs que j'ai achetées sont belles.
- Quelles fleurs as-tu achetées ?

> Pas d'accord avec **en** ni avec un **COI**.

- Des fleurs, j'en ai acheté.
- Je leur ai parlé.

> Pour les **verbes pronominaux**, le participe passé s'accorde généralement avec le sujet, sauf si **se** est un **COI** ou si un **COD** suit le verbe.

- Elle s'est levée.
- Elle s'est lavé les mains. (COD = les mains, après le verbe)
- Ils se sont parlé. (parler **à** quelqu'un → se = COI)

> Ces règles s'appliquent à tous les temps composés.

### L'imparfait

> Sujet + imparfait

**Exemple :** Quand j'étais enfant, je gagnais toujours.

| Sujet      | 1<sup>er</sup> | 2<sup>e</sup> |
| ---------- | -------------- | ------------- |
| Je         | -ais           | -issais       |
| Tu         | -ais           | -issais       |
| Il/Elle/On | -ait           | -issait       |
| Nous       | -ions          | -issions      |
| Vous       | -iez           | -issiez       |
| Ils/Elles  | -aient         | -issaient     |

#### Verbes fréquents

| Verbe   | Je      | Tu      | Il/Elle/On | Nous     | Vous    | Ils/Elles |
| ------- | ------- | ------- | ---------- | -------- | ------- | --------- |
| avoir   | avais   | avais   | avait      | avions   | aviez   | avaient   |
| être    | étais   | étais   | était      | étions   | étiez   | étaient   |
| aller   | allais  | allais  | allait     | allions  | alliez  | allaient  |
| venir   | venais  | venais  | venait     | venions  | veniez  | venaient  |
| faire   | faisais | faisais | faisait    | faisions | faisiez | faisaient |
| savoir  | savais  | savais  | savait     | savions  | saviez  | savaient  |
| pouvoir | pouvais | pouvais | pouvait    | pouvions | pouviez | pouvaient |
| vouloir | voulais | voulais | voulait    | voulions | vouliez | voulaient |

#### Formation

> forme de **nous** au présent - **-ons** + terminaison

- gagner → nous gagnons → gagn-
- finir → nous finissons → finiss-
- avoir → nous avons → av-
- aller → nous allons → all-
- venir → nous venons → ven-
- faire → nous faisons → fais-
- savoir → nous savons → sav-
- pouvoir → nous pouvons → pouv-
- vouloir → nous voulons → voul-

#### Exception

> être → **ét-**

### Le plus-que-parfait

> Sujet + avoir / être (imparfait) + participe passé

**Exemple :** Quand tu es arrivé, j'avais déjà gagné.

| Sujet      | avoir / être      | 1<sup>er</sup> | 2<sup>e</sup> |
| ---------- | ----------------- | -------------- | ------------- |
| Je         | avais / étais     | -é             | -i            |
| Tu         | avais / étais     | -é             | -i            |
| Il/Elle/On | avait / était     | -é             | -i            |
| Nous       | avions / étions   | -é             | -i            |
| Vous       | aviez / étiez     | -é             | -i            |
| Ils/Elles  | avaient / étaient | -é             | -i            |

> Avec **être**, le participe passé s'accorde généralement avec le sujet.

---

### Le passé récent

> Sujet + venir (présent) + de + infinitif

**Exemple :** Je viens de gagner le match !

| Sujet      | venir + de  | infinitif |
| ---------- | ----------- | --------- |
| Je         | viens de    | infinitif |
| Tu         | viens de    | infinitif |
| Il/Elle/On | vient de    | infinitif |
| Nous       | venons de   | infinitif |
| Vous       | venez de    | infinitif |
| Ils/Elles  | viennent de | infinitif |

> **de** devient **d'** devant une voyelle ou un _h_ muet.

**Exemple :** Je viens d'oublier son nom.

---

### Passé composé ou imparfait ?

| Passé composé                       | Imparfait                    |
| ----------------------------------- | ---------------------------- |
| action terminée, ponctuelle         | description, décor           |
| événement qui fait avancer le récit | circonstances, sentiments    |
| action limitée dans le temps        | habitude dans le passé       |
| action soudaine qui interrompt      | action en cours, interrompue |

- Il faisait beau et les enfants jouaient dans le parc. (décor)
- Soudain, il a commencé à pleuvoir. (événement)
- Je lisais quand le téléphone a sonné. (action en cours + interruption)
- Chaque été, nous allions à la mer. (habitude)
- L'été dernier, nous sommes allés à la mer. (une seule fois)

> Une durée précise (**pendant cinq ans**, **de 2010 à 2015**) entraîne le **passé composé**, même pour une action longue.

- J'ai habité à Lyon pendant cinq ans.

> Le **plus-que-parfait** exprime une action antérieure à une autre action passée.

- Quand je suis arrivé, le film avait déjà commencé.

#### Indices

- **Passé composé** : hier, soudain, tout à coup, un jour, ce jour-là, une fois, pendant + durée
- **Imparfait** : autrefois, d'habitude, chaque jour, tous les étés, à cette époque, quand j'étais petit

## Futur

### Le futur simple

> Sujet + radical du futur + terminaison

**Exemple :** Je gagnerai le match !

| Sujet      | terminaison |
| ---------- | ----------- |
| Je         | -ai         |
| Tu         | -as         |
| Il/Elle/On | -a          |
| Nous       | -ons        |
| Vous       | -ez         |
| Ils/Elles  | -ont        |

#### Formation

Pour les verbes réguliers :

> infinitif + terminaison

- gagner → je gagnerai
- finir → je finirai

Pour les verbes en **-re** :

> infinitif sans le **e** final + terminaison

- vendre → je vendrai

#### Verbes fréquents

| Verbe   | Je       | Tu       | Il/Elle/On | Nous      | Vous     | Ils/Elles |
| ------- | -------- | -------- | ---------- | --------- | -------- | --------- |
| avoir   | aurai    | auras    | aura       | aurons    | aurez    | auront    |
| être    | serai    | seras    | sera       | serons    | serez    | seront    |
| aller   | irai     | iras     | ira        | irons     | irez     | iront     |
| venir   | viendrai | viendras | viendra    | viendrons | viendrez | viendront |
| faire   | ferai    | feras    | fera       | ferons    | ferez    | feront    |
| savoir  | saurai   | sauras   | saura      | saurons   | saurez   | sauront   |
| pouvoir | pourrai  | pourras  | pourra     | pourrons  | pourrez  | pourront  |
| vouloir | voudrai  | voudras  | voudra     | voudrons  | voudrez  | voudront  |

> Le radical du futur se termine généralement par **-r**.

---

### Le futur proche

> Sujet + aller (présent) + infinitif

**Exemple :** Je vais gagner le match !

| Sujet      | aller  | infinitif |
| ---------- | ------ | --------- |
| Je         | vais   | infinitif |
| Tu         | vas    | infinitif |
| Il/Elle/On | va     | infinitif |
| Nous       | allons | infinitif |
| Vous       | allez  | infinitif |
| Ils/Elles  | vont   | infinitif |

---

### Le futur antérieur

> Sujet + avoir / être (futur simple) + participe passé

**Exemple :** Demain à midi, j'aurai gagné.

| Sujet      | avoir / être    | participe passé |
| ---------- | --------------- | --------------- |
| Je         | aurai / serai   | participe passé |
| Tu         | auras / seras   | participe passé |
| Il/Elle/On | aura / sera     | participe passé |
| Nous       | aurons / serons | participe passé |
| Vous       | aurez / serez   | participe passé |
| Ils/Elles  | auront / seront | participe passé |

> Avec **être**, le participe passé s'accorde généralement avec le sujet.

#### Emplois

- **Action terminée avant un moment futur** : Demain à midi, j'aurai fini.
- **Action terminée avant une autre action future** : Quand tu auras fini, tu m'appelleras.
- **Supposition sur le passé** : Il n'est pas venu ? Il aura oublié.

> Si le verbe principal est au **futur**, on emploie aussi le **futur** après **quand**, **lorsque**, **dès que**, **aussitôt que** et **une fois que**, contrairement à l'anglais.

- Quand j'arriverai, je t'appellerai. (et non « Quand j'arrive, je t'appellerai »)
- Dès que j'aurai reçu ta réponse, je réserverai les billets.

## Conditionnel

### Le conditionnel présent

> Sujet + radical du futur + terminaisons de l'imparfait

**Exemple :** J'habiterais à Bordeaux si je n'habitais pas à Paris.

#### Avec « si »

> Si + sujet + imparfait, sujet + conditionnel présent

**Exemple :** Si je jouais, je gagnerais.

| Sujet      | terminaison |
| ---------- | ----------- |
| Je         | -ais        |
| Tu         | -ais        |
| Il/Elle/On | -ait        |
| Nous       | -ions       |
| Vous       | -iez        |
| Ils/Elles  | -aient      |

#### Verbes fréquents

| Verbe   | Je        | Tu        | Il/Elle/On | Nous       | Vous      | Ils/Elles   |
| ------- | --------- | --------- | ---------- | ---------- | --------- | ----------- |
| avoir   | aurais    | aurais    | aurait     | aurions    | auriez    | auraient    |
| être    | serais    | serais    | serait     | serions    | seriez    | seraient    |
| aller   | irais     | irais     | irait      | irions     | iriez     | iraient     |
| venir   | viendrais | viendrais | viendrait  | viendrions | viendriez | viendraient |
| faire   | ferais    | ferais    | ferait     | ferions    | feriez    | feraient    |
| savoir  | saurais   | saurais   | saurait    | saurions   | sauriez   | sauraient   |
| pouvoir | pourrais  | pourrais  | pourrait   | pourrions  | pourriez  | pourraient  |
| vouloir | voudrais  | voudrais  | voudrait   | voudrions  | voudriez  | voudraient  |

> Le **futur simple** et le **conditionnel présent** utilisent les mêmes radicaux.

#### Emplois

- **Hypothèse** : Si j'avais le temps, je voyagerais.
- **Politesse** : Pourriez-vous m'aider ? / Je voudrais un café.
- **Souhait** : J'aimerais vivre au bord de la mer.
- **Conseil** : Tu devrais te reposer. / À ta place, je partirais.
- **Éventualité** : Prends un parapluie au cas où il pleuvrait.
- **Information non confirmée** : Le ministre serait sur le point de démissionner.
- **Futur dans le passé** : Il a dit qu'il viendrait.

> **au cas où** est suivi du **conditionnel**.

> Dans la presse, le conditionnel signale une information **non vérifiée**.

---

### Le conditionnel passé

> Sujet + avoir / être (conditionnel présent) + participe passé

**Exemple :** J'aurais gagné.

#### Avec « si »

> Si + sujet + plus-que-parfait, sujet + conditionnel passé

**Exemple :** Si j'avais joué, j'aurais gagné.

| Sujet      | avoir / être        | participe passé |
| ---------- | ------------------- | --------------- |
| Je         | aurais / serais     | participe passé |
| Tu         | aurais / serais     | participe passé |
| Il/Elle/On | aurait / serait     | participe passé |
| Nous       | aurions / serions   | participe passé |
| Vous       | auriez / seriez     | participe passé |
| Ils/Elles  | auraient / seraient | participe passé |

> Avec **être**, le participe passé s'accorde généralement avec le sujet.

#### Emplois

- **Hypothèse non réalisée** : Si j'avais su, je serais venu.
- **Regret** : J'aurais aimé être là.
- **Reproche** : Tu aurais dû me prévenir. / Vous auriez pu appeler !
- **Information non confirmée** : L'incendie aurait fait trois victimes.
- **Futur antérieur dans le passé** : Il a dit qu'il aurait fini avant midi.

#### Règle avec « si »

> Si + présent → présent / futur / impératif

> Si + imparfait → conditionnel présent

> Si + plus-que-parfait → conditionnel passé

> On ne met normalement pas **conditionnel** directement après **si**.

#### Hypothèses mixtes

> Si + plus-que-parfait → conditionnel présent, quand la conséquence concerne le présent.

- Si j'avais étudié la médecine, je serais médecin aujourd'hui.

> Si + imparfait → conditionnel passé, quand la condition est permanente.

- Si j'étais plus prudent, je n'aurais pas eu cet accident.

## Impératif

### L'impératif

> Verbe conjugué sans pronom sujet

Il existe principalement pour :

> **tu / nous / vous**

**Exemple :** Gagne ce match !

| Personne | 1<sup>er</sup> | 2<sup>e</sup> |
| -------- | -------------- | ------------- |
| Tu       | -e             | -is           |
| Nous     | -ons           | -issons       |
| Vous     | -ez            | -issez        |

#### Verbes fréquents

| Verbe   | tu      | nous      | vous     |
| ------- | ------- | --------- | -------- |
| avoir   | aie     | ayons     | ayez     |
| être    | sois    | soyons    | soyez    |
| aller   | va      | allons    | allez    |
| venir   | viens   | venons    | venez    |
| faire   | fais    | faisons   | faites   |
| savoir  | sache   | sachons   | sachez   |
| vouloir | veuille | veuillons | veuillez |

> **pouvoir** n'a pas de forme d'impératif ; on utilise généralement **tu peux** / **vous pouvez** au présent, ou une autre tournure.

> Les formes de **vouloir** sont rares, sauf **veuillez**, très courant dans les formules de politesse.

**Exemple :** Veuillez patienter quelques instants.

#### Verbes en -er

À la deuxième personne du singulier, les verbes réguliers en **-er** perdent généralement le **-s**.

> Tu gagnes → Gagne !

> Tu regardes → Regarde !

Mais le **-s** revient devant **y** et **en**.

> Va → Vas-y !

> Mange → Manges-en !

## Infinitif

### L'infinitif passé

> avoir / être (infinitif) + participe passé

**Exemple :** Après avoir mangé, il est sorti.

Il exprime une action **terminée avant** celle du verbe principal. Le sujet est le même dans les deux parties de la phrase.

- **après** + infinitif passé : Après être arrivée, elle a appelé sa mère.
- **sans** + infinitif passé : Il est parti sans avoir dit au revoir.
- **pour** + infinitif passé (cause) : Il a été puni pour avoir menti.
- **verbe / adjectif + de** + infinitif passé : Je suis content d'avoir réussi.

> **après** est suivi de l'infinitif **passé** : après avoir mangé, et non « après manger ».

> **avant de** est suivi de l'infinitif **présent** : Avant de partir, ferme la fenêtre.

> À la négation, **ne pas** se place avant l'auxiliaire : Je regrette de ne pas être venu.

> Avec **être**, le participe passé s'accorde avec le sujet.

---

## Participe présent et gérondif

### Le gérondif

> en + participe présent

**Exemple :** En travaillant régulièrement, on progresse plus vite.

#### Formation

> forme de **nous** au présent - **-ons** + **-ant**

- nous gagnons → gagnant
- nous finissons → finissant
- nous faisons → faisant
- nous venons → venant

#### Exceptions fréquentes

- avoir → **ayant**
- être → **étant**
- savoir → **sachant**

**Exemple :** En passant...

#### Emplois

- **Simultanéité** : Il chante en se douchant.
- **Manière / moyen** : Il a appris le français en regardant des films.
- **Condition** : En partant maintenant, tu arriveras à l'heure.
- **Opposition** (avec **tout**) : Tout en étant fatigué, il a continué.

> Le sujet du gérondif est toujours le même que celui du verbe principal.

---

### Le participe présent

> forme de **nous** au présent - **-ons** + **-ant**, sans **en**

Surtout à l'écrit. Il remplace une proposition relative avec **qui** ou exprime une cause.

- **= qui + verbe** : Je cherche un assistant parlant chinois. (= qui parle chinois)
- **Cause** : Étant malade, il n'est pas venu. (= comme il était malade)

> Le participe présent est **invariable**.

#### Participe présent ou gérondif ?

| Gérondif                          | Participe présent                |
| --------------------------------- | -------------------------------- |
| en + -ant                         | -ant                             |
| même sujet que le verbe principal | peut se rapporter à un autre nom |
| manière, moyen, simultanéité      | cause, ou remplace qui + verbe   |

- J'ai vu Paul en sortant du cinéma. (c'est **moi** qui sortais)
- J'ai vu Paul sortant du cinéma. (c'est **Paul** qui sortait)

---

### Le participe composé

> ayant / étant + participe passé

Il exprime une action **terminée avant** l'action principale, souvent avec une valeur de cause. Surtout à l'écrit.

**Exemple :** Ayant terminé son travail, elle est rentrée chez elle.

- Étant arrivés en retard, ils ont manqué le début du film.

> Avec **étant**, le participe passé s'accorde avec le sujet.

---

## Subjonctif

### Le subjonctif présent

> que / qu' + sujet + subjonctif présent

**Exemple :** Il faut que je gagne.

| Sujet      | 1<sup>er</sup> | 2<sup>e</sup> |
| ---------- | -------------- | ------------- |
| Je         | -e             | -isse         |
| Tu         | -es            | -isses        |
| Il/Elle/On | -e             | -isse         |
| Nous       | -ions          | -issions      |
| Vous       | -iez           | -issiez       |
| Ils/Elles  | -ent           | -issent       |

#### Verbes fréquents

| Verbe   | Je      | Tu       | Il/Elle/On | Nous      | Vous     | Ils/Elles |
| ------- | ------- | -------- | ---------- | --------- | -------- | --------- |
| avoir   | aie     | aies     | ait        | ayons     | ayez     | aient     |
| être    | sois    | sois     | soit       | soyons    | soyez    | soient    |
| aller   | aille   | ailles   | aille      | allions   | alliez   | aillent   |
| venir   | vienne  | viennes  | vienne     | venions   | veniez   | viennent  |
| faire   | fasse   | fasses   | fasse      | fassions  | fassiez  | fassent   |
| savoir  | sache   | saches   | sache      | sachions  | sachiez  | sachent   |
| pouvoir | puisse  | puisses  | puisse     | puissions | puissiez | puissent  |
| vouloir | veuille | veuilles | veuille    | voulions  | vouliez  | veuillent |

#### Formation

> forme de **ils** au présent - **-ent** + terminaison

- parler → ils parlent → parl-
- finir → ils finissent → finiss-
- prendre → ils prennent → prenn-
- boire → ils boivent → boiv-
- venir → ils viennent → vienn-

> Les **verbes fréquents** ci-dessus ne suivent pas cette règle, sauf **venir**.

- pouvoir → ils peuvent → que je **puisse**, et non « peuve »
- vouloir → ils veulent → que je **veuille**, et non « veule »

> Pour **nous** et **vous**, on utilise généralement la forme de **nous** au présent - **-ons**.

- prendre → nous prenons → pren- → que nous prenions
- boire → nous buvons → buv- → que nous buvions
- venir → nous venons → ven- → que nous venions

> **aller** et **vouloir** suivent cette règle pour **nous** et **vous**, alors que leur radical est irrégulier ailleurs : que j'**aille** / que nous **allions**, que je **veuille** / que nous **voulions**.

Donc certains verbes ont **deux radicaux** au subjonctif :

> **ils - ent** → je, tu, il/elle/on, ils/elles  
> **nous - ons** → nous, vous

#### Déclencheurs

Le subjonctif présente une action comme **envisagée** (nécessité, souhait, sentiment, doute) plutôt que comme un fait.

##### Nécessité et obligation

- Il faut que...
- Il est nécessaire que...
- Il est essentiel que...
- Il est indispensable que...
- Il est important que...
- Il est urgent que...
- Il est temps que...
- Il vaut mieux que...
- Il est préférable que...
- Il suffit que...

**Exemple :** Il est temps que nous partions.

##### Volonté et souhait

- Je veux que...
- Je souhaite que...
- J'aimerais que...
- Je préfère que...
- Je demande que...
- J'exige que...
- Je propose que...
- Je tiens à ce que...
- Je m'attends à ce que...
- J'accepte que...
- Je refuse que...
- Je m'oppose à ce que...

**Exemple :** Je tiens à ce que tu sois là.

##### Sentiments

- Je suis heureux / content que...
- Je suis ravi que...
- Je suis fier que...
- Je suis triste que...
- Je suis désolé que...
- Je suis déçu que...
- Je suis surpris / étonné que...
- Je regrette que...
- J'ai peur que... / Je crains que...
- Ça me dérange que...

**Exemple :** Je suis désolé que tu ne puisses pas venir.

##### Jugement et appréciation

- C'est dommage que...
- C'est incroyable que...
- C'est bien que...
- Il est normal que...
- Il est rare que...
- Il est surprenant que...
- Il est étonnant que...
- Il est logique que...
- Il est naturel que...
- Il est regrettable que...
- Il est inadmissible que...
- Il est inacceptable que...
- Il est scandaleux que...

**Exemple :** C'est dommage qu'il pleuve aujourd'hui.

##### Doute et possibilité

- Je doute que...
- Il est possible que...
- Il est impossible que...
- Il se peut que...
- Il est peu probable que...
- Il semble que...
- Il n'est pas sûr / certain que...
- Je ne suis pas sûr que...
- Je ne pense pas que...
- Je ne crois pas que...

**Exemple :** Il se peut qu'il soit en retard.

##### Conjonctions

- **But** : pour que, afin que, de sorte que
- **Crainte** : de peur que, de crainte que
- **Temps** : avant que, jusqu'à ce que, en attendant que
- **Concession** : bien que, quoique, encore que
- **Condition** : à condition que, pourvu que, à moins que, à supposer que, en admettant que
- **Manière** : sans que
- **Indéfini** : quoi que, qui que, où que, quel(le)(s) que

**Exemple :** Bien qu'il soit fatigué, il continue.

**Exemple :** Quel que soit le résultat, je suis fier de toi.

##### Superlatif et relatives

- C'est le meilleur / le pire... que...
- le seul / l'unique... qui / que...
- le premier / le dernier... qui / que...
- Je cherche quelqu'un qui...

**Exemple :** C'est le meilleur film que j'aie jamais vu.

**Exemple :** Je cherche quelqu'un qui sache parler chinois.

#### Indicatif ou subjonctif ?

| Indicatif                     | Subjonctif                 |
| ----------------------------- | -------------------------- |
| Je pense que...               | Je ne pense pas que...     |
| Je crois que...               | Je ne crois pas que...     |
| Je suis sûr que...            | Je ne suis pas sûr que...  |
| Il est probable que...        | Il est peu probable que... |
| Il est évident / clair que... | Il est possible que...     |
| Il me semble que...           | Il semble que...           |
| J'espère que...               | Je souhaite que...         |
| même si                       | bien que                   |
| après que                     | avant que                  |
| de sorte que (conséquence)    | de sorte que (but)         |

> **après que** se construit avec l'indicatif selon la norme, mais on entend très souvent le subjonctif à l'oral. À l'écrit et à l'examen, on emploie l'indicatif.

- Je t'appellerai après que tu seras rentré. (et non « après que tu sois rentré »)

> **Il semble que** prend généralement le subjonctif, mais l'indicatif est possible quand le fait paraît presque certain, surtout avec **il semble bien que**.

- Il semble qu'il y ait un problème. (impression)
- Il semble bien qu'il y a un problème. (presque certain)

> Même sujet dans les deux propositions → **infinitif**, pas de subjonctif.

- Je veux partir. (et non « Je veux que je parte »)
- Je suis content d'être ici.
- Je travaille pour réussir. / Je travaille pour que mes enfants réussissent.

> Après **avant que**, **à moins que**, **de peur que**, **avoir peur que** et **craindre que**, on peut ajouter un **ne explétif** (registre soutenu). Il n'a pas de sens négatif.

- J'ai peur qu'il ne pleuve. = J'ai peur qu'il pleuve.
- Partons avant qu'il ne soit trop tard.

> Avec une question par inversion, **penser** et **croire** peuvent prendre le subjonctif.

- Penses-tu qu'il soit prêt ?

---

### Le subjonctif passé

> que / qu' + sujet + avoir / être (subjonctif présent) + participe passé

**Exemple :** Je suis heureux que tu aies gagné.

| Sujet      | avoir / être   | participe passé |
| ---------- | -------------- | --------------- |
| Je         | aie / sois     | participe passé |
| Tu         | aies / sois    | participe passé |
| Il/Elle/On | ait / soit     | participe passé |
| Nous       | ayons / soyons | participe passé |
| Vous       | ayez / soyez   | participe passé |
| Ils/Elles  | aient / soient | participe passé |

> Avec **être**, le participe passé s'accorde généralement avec le sujet.

## Discours rapporté

### Le discours indirect

> Sujet + verbe introducteur + que / si / mot interrogatif + proposition

**Exemple :** Il dit : « Je suis fatigué. » → Il dit qu'il est fatigué.

#### Verbes introducteurs

- dire, affirmer, déclarer, annoncer
- expliquer, préciser, ajouter, souligner
- répondre, reconnaître, avouer, admettre
- demander, se demander, vouloir savoir
- promettre, prétendre

#### Questions et ordres

| Discours direct              | Discours indirect               |
| ---------------------------- | ------------------------------- |
| « Tu viens ? »               | Il demande **si** tu viens.     |
| « Qu'est-ce que tu fais ? »  | Il demande **ce que** tu fais.  |
| « Qu'est-ce qui se passe ? » | Il demande **ce qui** se passe. |
| « Où vas-tu ? »              | Il demande **où** tu vas.       |
| « Viens ! »                  | Il te dit **de** venir.         |

> Au discours indirect, pas d'inversion du sujet ni de point d'interrogation.

#### Concordance des temps

> Si le verbe introducteur est au **passé**, le temps de la phrase rapportée change.

| Discours direct | Discours indirect (passé)            |
| --------------- | ------------------------------------ |
| présent         | imparfait                            |
| passé composé   | plus-que-parfait                     |
| futur simple    | conditionnel présent                 |
| futur antérieur | conditionnel passé                   |
| futur proche    | aller à l'imparfait + infinitif      |
| passé récent    | venir à l'imparfait + de + infinitif |

- « Je suis fatigué. » → Il a dit qu'il était fatigué.
- « J'ai fini. » → Il a dit qu'il avait fini.
- « Je viendrai. » → Il a dit qu'il viendrait.
- « J'aurai fini à midi. » → Il a dit qu'il aurait fini à midi.
- « Je vais partir. » → Il a dit qu'il allait partir.
- « Je viens d'arriver. » → Il a dit qu'il venait d'arriver.

> L'**imparfait**, le **plus-que-parfait**, le **conditionnel** et le **subjonctif** ne changent pas.

> Les **pronoms** et les **possessifs** changent aussi selon la personne qui parle : « Je prends **ma** voiture. » → Il a dit qu'il prenait **sa** voiture.

#### Indicateurs de temps et de lieu

| Discours direct      | Discours indirect (passé) |
| -------------------- | ------------------------- |
| aujourd'hui          | ce jour-là                |
| maintenant           | à ce moment-là            |
| hier                 | la veille                 |
| avant-hier           | l'avant-veille            |
| demain               | le lendemain              |
| après-demain         | le surlendemain           |
| ce matin / ce soir   | ce matin-là / ce soir-là  |
| la semaine dernière  | la semaine précédente     |
| la semaine prochaine | la semaine suivante       |
| il y a deux jours    | deux jours plus tôt       |
| dans deux jours      | deux jours plus tard      |
| ici                  | là                        |

## Voix passive

### La voix passive

> Sujet + être (conjugué) + participe passé (+ par / de + agent)

**Exemple :** Ce musée a été construit en 1900.

Le COD de la phrase active devient le sujet. On l'emploie pour mettre en avant l'action ou le résultat, ou quand on ne connaît pas l'auteur de l'action.

> Le temps est porté par **être** ; le participe passé s'accorde avec le sujet.

| Temps         | Voix active                    | Voix passive                       |
| ------------- | ------------------------------ | ---------------------------------- |
| Présent       | On répare la route.            | La route est réparée.              |
| Passé composé | On a réparé la route.          | La route a été réparée.            |
| Imparfait     | On réparait la route.          | La route était réparée.            |
| Futur simple  | On réparera la route.          | La route sera réparée.             |
| Conditionnel  | On réparerait la route.        | La route serait réparée.           |
| Subjonctif    | Il faut qu'on répare la route. | Il faut que la route soit réparée. |

> Au passé composé, l'auxiliaire est **avoir été** : la route **a été** réparée, et non « est été ».

> Seuls les verbes qui ont un **COD** peuvent se mettre au passif : on ne peut pas dire « Marie a été parlée ».

#### par ou de ?

- **par** : cas général, surtout pour une action — La lettre a été écrite par Marie.
- **de** : avec les verbes de sentiment ou de description — Il est aimé de tous. / La table est couverte de livres.

#### Autres tournures

- **on** + voix active : On m'a volé mon vélo.
- **se faire** + infinitif : Il s'est fait voler son vélo. (action subie)
- **verbe pronominal** : Ce plat se mange froid. / Ce livre se vend bien.

## Périphrases verbales

> Verbe conjugué + infinitif

Elles précisent **à quel moment** de l'action on se trouve.

| Moment       | Périphrase                            | Exemple                              |
| ------------ | ------------------------------------- | ------------------------------------ |
| Bientôt      | aller + infinitif                     | Il va pleuvoir.                      |
| Juste avant  | être sur le point de + infinitif      | Le train est sur le point de partir. |
| Début        | se mettre à / commencer à + infinitif | Il s'est mis à pleuvoir.             |
| En cours     | être en train de + infinitif          | Je suis en train de travailler.      |
| Continuation | continuer à + infinitif               | Elle continue à travailler.          |
| Fin          | finir de / arrêter de + infinitif     | J'ai fini de manger.                 |
| Juste après  | venir de + infinitif                  | Il vient de partir.                  |
| Presque      | faillir + infinitif                   | J'ai failli tomber.                  |

> Elles se conjuguent à tous les temps.

- J'étais en train de dormir quand tu as appelé.
- Il allait partir quand le téléphone a sonné.
- Je venais d'arriver.

> **être en train de** sert à insister sur l'action en cours. Sinon, le présent suffit : Je travaille.

## Faire et laisser + infinitif

### Le faire causatif

> Sujet + faire (conjugué) + infinitif

Le sujet ne fait pas l'action lui-même : il la fait faire par quelqu'un d'autre.

**Exemple :** Je fais réparer ma voiture. (= un garagiste la répare)

- Le professeur fait lire les élèves.
- J'ai fait construire une maison.
- Ce film m'a fait rire.

> La personne qui fait l'action est introduite par **par**, ou par **à** quand il y a déjà un COD.

- Je fais réparer ma voiture par un garagiste.
- Je fais lire ce texte aux élèves.

> Les pronoms se placent **devant faire**.

- Je la fais réparer.
- Je le leur fais lire.

> Le participe **fait** reste **invariable** devant un infinitif.

- La maison que j'ai fait construire.
- Elle s'est fait couper les cheveux.

### se faire + infinitif

- Elle s'est fait couper les cheveux. (chez le coiffeur)
- Il s'est fait voler son portefeuille. (action subie)
- Je me suis fait comprendre.

### laisser + infinitif

> Sujet + laisser (conjugué) + infinitif : permettre, ne pas empêcher

- Laisse-moi parler !
- Il laisse ses enfants jouer dehors.
- J'ai laissé tomber mon téléphone.

> **laisser tomber** signifie aussi **abandonner** (familier) : Laisse tomber, ce n'est pas grave.

## Temps littéraires

Ces temps apparaissent surtout dans la littérature, les récits historiques et certains textes très soutenus.

---

### Le passé simple

> Sujet + passé simple

Temps narratif utilisé principalement à l'écrit pour des actions terminées.

**Exemple :** Il entra dans la pièce et ferma la porte.

À l'oral, on emploie généralement le **passé composé**.

> Je gagnai → J'ai gagné

#### Verbes réguliers

| Sujet      | gagner    | finir    | vendre    |
| ---------- | --------- | -------- | --------- |
| Je         | gagnai    | finis    | vendis    |
| Tu         | gagnas    | finis    | vendis    |
| Il/Elle/On | gagna     | finit    | vendit    |
| Nous       | gagnâmes  | finîmes  | vendîmes  |
| Vous       | gagnâtes  | finîtes  | vendîtes  |
| Ils/Elles  | gagnèrent | finirent | vendirent |

#### Verbes très fréquents

| Verbe | Je  | Tu  | Il/Elle/On | Nous  | Vous  | Ils/Elles |
| ----- | --- | --- | ---------- | ----- | ----- | --------- |
| avoir | eus | eus | eut        | eûmes | eûtes | eurent    |
| être  | fus | fus | fut        | fûmes | fûtes | furent    |

> Il fut...

> Ils furent...

> Il eut...

> Ils eurent...

---

### Le passé antérieur

> Sujet + avoir / être (passé simple) + participe passé

Il indique généralement une action achevée juste avant une autre action au passé simple.

**Exemple :** Quand il eut terminé, il partit.

À l'oral ou dans un style moins littéraire, on emploie généralement le **plus-que-parfait**.

> J'eus gagné → J'avais gagné

| Sujet      | avoir / être    |
| ---------- | --------------- |
| Je         | eus / fus       |
| Tu         | eus / fus       |
| Il/Elle/On | eut / fut       |
| Nous       | eûmes / fûmes   |
| Vous       | eûtes / fûtes   |
| Ils/Elles  | eurent / furent |

---

### Le subjonctif imparfait

> que / qu' + sujet + subjonctif imparfait

Forme littéraire aujourd'hui très rare dans la langue courante.

**Exemple :** Il fallait que je gagnasse.

Dans le français courant :

> Il fallait que je gagne.

#### Exemple avec « gagner »

| Sujet      | gagner      |
| ---------- | ----------- |
| Je         | gagnasse    |
| Tu         | gagnasses   |
| Il/Elle/On | gagnât      |
| Nous       | gagnassions |
| Vous       | gagnassiez  |
| Ils/Elles  | gagnassent  |

---

### Le subjonctif plus-que-parfait

> que / qu' + sujet + avoir / être (subjonctif imparfait) + participe passé

Forme littéraire très rare.

**Exemple :** Il aurait fallu que j'eusse gagné.

Dans le français courant, on emploie généralement le **subjonctif passé**.

> que j'eusse gagné → que j'aie gagné

#### Auxiliaires

| Verbe | Je    | Tu     | Il/Elle/On | Nous     | Vous    | Ils/Elles |
| ----- | ----- | ------ | ---------- | -------- | ------- | --------- |
| avoir | eusse | eusses | eût        | eussions | eussiez | eussent   |
| être  | fusse | fusses | fût        | fussions | fussiez | fussent   |

---

### Le conditionnel passé (2<sup>e</sup> forme)

> Sujet + avoir / être (subjonctif imparfait) + participe passé

Forme littéraire ancienne du conditionnel passé.

**Exemple :** J'eusse gagné.

Dans le français courant :

> J'aurais gagné.

Sa forme est identique à celle du **subjonctif plus-que-parfait**.
