# Les homophones grammaticaux

## Liens utiles

- [Les temps du français sur LA LANGUE FRANÇAISE](/cours/grammaire/temps)

> Les homophones se prononcent de la même façon mais s'écrivent différemment. Pour choisir, on remplace le mot par un autre : si la phrase reste correcte, c'est la bonne forme.

---

## Terminaisons en [e]

### -é / -er / -ez / -ais / -ait

| Forme           | Astuce                                | Exemple                     |
| --------------- | ------------------------------------- | --------------------------- |
| -er (infinitif) | on peut dire **prendre** / **vendre** | Je vais manger.             |
| -é (participe)  | on peut dire **pris** / **vendu**     | J'ai mangé.                 |
| -ez             | sujet **vous**                        | Vous mangez.                |
| -ais / -ait     | imparfait : on peut dire **prenais**  | Je mangeais. / Il mangeait. |

- Je vais **manger**. → Je vais **prendre**. (infinitif)
- J'ai **mangé**. → J'ai **pris**. (participe passé)

> Après une **préposition** (à, de, pour, sans...), le verbe est à l'**infinitif** : Il est parti sans **manger**.

## Homophones de base

### a / à

| Mot | Astuce                    | Exemple        |
| --- | ------------------------- | -------------- |
| a   | verbe avoir : → **avait** | Il a faim.     |
| à   | préposition               | Il va à Paris. |

### et / est

| Mot | Astuce                   | Exemple         |
| --- | ------------------------ | --------------- |
| et  | → **et puis**            | Paul et Marie.  |
| est | verbe être : → **était** | Il est content. |

### on / ont

| Mot | Astuce                      | Exemple         |
| --- | --------------------------- | --------------- |
| on  | pronom : → **il**           | On part demain. |
| ont | verbe avoir : → **avaient** | Ils ont fini.   |

### son / sont

| Mot  | Astuce                     | Exemple          |
| ---- | -------------------------- | ---------------- |
| son  | possessif : → **mon**      | C'est son livre. |
| sont | verbe être : → **étaient** | Ils sont partis. |

### ou / où

| Mot | Astuce                | Exemple                     |
| --- | --------------------- | --------------------------- |
| ou  | choix : → **ou bien** | Du thé ou du café ?         |
| où  | lieu ou temps         | Où vas-tu ? / Le jour où... |

### ce / se

| Mot | Astuce                                      | Exemple             |
| --- | ------------------------------------------- | ------------------- |
| ce  | démonstratif : → **cet**, **cela**          | Ce livre est à moi. |
| se  | pronom réfléchi, devant un verbe : → **me** | Il se lève tôt.     |

### ces / ses / c'est / s'est

| Mot   | Astuce                                       | Exemple                |
| ----- | -------------------------------------------- | ---------------------- |
| ces   | démonstratif : → **ces... -là**              | Ces livres sont chers. |
| ses   | possessif : → **mes**                        | Il range ses affaires. |
| c'est | → **cela est**                               | C'est difficile.       |
| s'est | verbe pronominal au passé : → **je me suis** | Il s'est trompé.       |

### la / l'a / là

| Mot | Astuce                       | Exemple                 |
| --- | ---------------------------- | ----------------------- |
| la  | article ou pronom : → **le** | La porte. / Je la vois. |
| l'a | → **l'avait**                | Il l'a vu.              |
| là  | lieu : → **ici**             | Pose-le là.             |

### peu / peut / peux

| Mot         | Astuce                        | Exemple        |
| ----------- | ----------------------------- | -------------- |
| peu         | contraire de **beaucoup**     | Il mange peu.  |
| peut / peux | verbe pouvoir : → **pouvait** | Il peut venir. |

## Homophones avancés

### leur / leurs

| Mot          | Astuce                                         | Exemple                     |
| ------------ | ---------------------------------------------- | --------------------------- |
| leur         | pronom devant un verbe : → **lui**, invariable | Je leur parle.              |
| leur / leurs | déterminant devant un nom, s'accorde           | Leur fils. / Leurs enfants. |

### quel / quelle / qu'elle

| Mot           | Astuce                     | Exemple                   |
| ------------- | -------------------------- | ------------------------- |
| quel / quelle | interrogatif ou exclamatif | Quelle heure est-il ?     |
| qu'elle       | → **qu'il**                | Je pense qu'elle viendra. |

### quand / quant / qu'en

| Mot     | Astuce                   | Exemple                |
| ------- | ------------------------ | ---------------------- |
| quand   | temps : → **lorsque**    | Quand pars-tu ?        |
| quant à | → **en ce qui concerne** | Quant à moi, je reste. |
| qu'en   | **que** + **en**         | Qu'en penses-tu ?      |

### ni / n'y

| Mot | Astuce                            | Exemple                         |
| --- | --------------------------------- | ------------------------------- |
| ni  | négation double : ni... ni        | Je n'aime ni le thé ni le café. |
| n'y | **ne** + **y** : → **n'y... pas** | Je n'y vais pas.                |

### sans / s'en

| Mot  | Astuce                          | Exemple             |
| ---- | ------------------------------- | ------------------- |
| sans | contraire de **avec**           | Un café sans sucre. |
| s'en | **se** + **en** : → **je m'en** | Il s'en va.         |

### plutôt / plus tôt

| Mot      | Astuce                     | Exemple                    |
| -------- | -------------------------- | -------------------------- |
| plutôt   | de préférence, assez       | Je prendrai plutôt du thé. |
| plus tôt | contraire de **plus tard** | Viens plus tôt demain.     |

### près / prêt

| Mot         | Astuce             | Exemple                  |
| ----------- | ------------------ | ------------------------ |
| près (de)   | proche, invariable | J'habite près d'ici.     |
| prêt(e) (à) | préparé, s'accorde | Elle est prête à partir. |

### quoique / quoi que

| Mot      | Astuce                                            | Exemple                            |
| -------- | ------------------------------------------------- | ---------------------------------- |
| quoique  | → **bien que** (+ subjonctif)                     | Quoiqu'il soit tard, il travaille. |
| quoi que | → **quelle que soit la chose que** (+ subjonctif) | Quoi que tu fasses, je t'aiderai.  |

### quelque / quel que

| Mot                    | Astuce                                       | Exemple                               |
| ---------------------- | -------------------------------------------- | ------------------------------------- |
| quelque(s)             | déterminant : → **un peu de**, **plusieurs** | J'ai quelques questions.              |
| quel(le)(s) que + être | s'accorde avec le sujet (+ subjonctif)       | Quelle que soit la réponse, je reste. |
